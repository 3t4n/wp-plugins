Easily Sync GetResponse Contacts With Your WordPress Users.

== Description ==

Fast GetResponse is designed to work seamlessly with both the [Fast Flow Dashboard](http://wordpress.org/plugins/fast-flow-dashboard/) and [Fast Member](https://fastmember.com)

Once your contacts have been added to WordPress you now have the ability to sync their Fast Tags and Fast Member purchases.

Fast Tags can be used to trigger automations on any other integrated platform which is supported by our growing number Fast Flow addons.

> NOTE: Fast GetResponse requires the Fast Flow Dashboard to enter the API details and utilise the user tagging.
>
>[http://wordpress.org/plugins/fast-flow-dashboard/](http://wordpress.org/plugins/fast-flow-dashboard/)

You can find out more about [Fast Flow](https://fastflow.io) here

[https://fastflow.io](https://fastflow.io)

== Installation ==

NOTE: This plugin requires the Fast Flow Dashboard to enter the GetResponse API settings.

Upload through your WordPress admin or via FTP.

Once uploaded simply activate  and then navigate to the settings of the Fast Flow Dashboard and enter your GetResponse API details.
