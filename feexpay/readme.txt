== Description ==

A secure plugin to accept Mobile Money and Credit Card payments.

FeexPay is a plugin designed for Woocommerce that allows you to accept mobile money or credit card payments on your various websites.

As an advantage, this plugin is very easy to use, intuitive and above all requires no integration costs.

Using FeexPay is choosing a fast, secure and reliable way to collect online payments.
