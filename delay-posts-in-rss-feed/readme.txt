Beat content scrapers and save yourself from accidental publishing by delaying posts in your RSS feed.

== Description ==
Check your feed status with http://www.example.com/feed.

*   **3 units of time are supported: seconds, hours, and minutes.**

For more information, Please visit [Delay Posts From Appearing in WordPress RSS Feed](https://www.inthiscode.com/delay-posts-in-rss-feed).

== Installation ==
Install using Plugins->Add New or manually upload using WordPress plugin uploader.
Activate the plugin, and go to the settings page for customization.
