== Description ==

Get your daily store reports with data that matters to you via automated emails. **Daily Snapshot for WooCommerce Admin** is an Add-On plugin for **WooCommerce Admin** .This plugin allows you to send automated analytics reports of your WooCommerce store to the multiple recipients. 

This add-on backup the data like Number of Orders, Items, Total Revenue, Gross Revenue, etc. from the Analytics dashboard provided by WooCommerce Admin plugin and compiles them into a single picture that can be shared by the merchant or the WooCommerce store-owner with the recipients through emails.


== MAIN FEATURES ==

* Easy to install and activate.
* WooCommerce Admin Analytics Dashboard Reports.
* Multiple recipients can be added in the list to share the data image.
* Email Notifications.
* No-complication Settings.
* Scheduled Reporting.
* One-Click Data Sharing.

== Installation ==

= Automatic installation =

Automatic installation is the easiest option as WordPress handles the file transfers itself and you don't need to leave your web browser. To do an automatic install of Daily Snapshot for WooCommerce Admin, log in to your WordPress dashboard, navigate to the Plugins menu and click Add New.

In the search field type "Daily Snapshot for WooCommerce Admin" and click Search Plugins. Once you've found our plugin you can view details about it such as the point release, rating and description. Most importantly of course, you can install it by simply clicking "Install Now".

= Manual installation =

The manual installation method involves downloading our Daily Snapshot for WooCommerce Admin and uploading it to your webserver via your favourite FTP application. The WordPress codex contains [instructions on how to do this here](http://codex.wordpress.org/Managing_Plugins#Manual_Plugin_Installation).

= Updating =

Automatic updates should work like a charm; as always though, ensure you backup your site just in case.

== Frequently Asked Questions ==

= For what timespan the plugin sends the woocommerce reports? =

The plugin use to monitor the last day report data from woocommerce admin plugin and generates the email report for same time period.

= Can I send an email to multiple recipients? =

Yes the generated reports can be sent to multiple email addresses. Please refer to the plugin settings once.

=  I activated the plugin but its not showing anywhere? =

Please make sure that your store has WooCommerce Admin plugin installed and activated.

= At what intervals the emails will be sent? =

The email reports will be sent daily to the emails saved in settings.
