Easily customize your WooCommerce store with features like "Add to Cart" button labels, product display settings, and quantity.

== Description ==

**Easy Store Customizer** is a lightweight and easy-to-use plugin for customizing your WooCommerce store without touching a single line of code. Tailor the shop and product pages to suit your business needs with just a few clicks.

### **Features:**

#### **Shop Page**

- **Rename the "Add to Cart" button label**: Customize the text for different product types for both the shop and single product pages.
- **Number of Products per Page**: Change the default number of products displayed per page from default 12 to any number you prefer.

#### **Product Page**

- **Add to Cart Quantity Plus & Minus Buttons**: Enhance the quantity input field with intuitive plus/minus buttons. so customers can easily adjust the quantity.
- **Hide Add to Cart Quantity Input Arrows**: Simplify the UI by removing arrows if the quantity plus/minus buttons are active.
- **Show Number of Products Sold**: Display the number of products sold on the single product page. It helps to build trust and credibility with your customers.

Stay tuned for more exciting features in upcoming updates!

== Installation ==

1. Download the plugin file.
2. Upload the `easy-store-customizer` folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the 'Plugins' screen in WordPress.
4. Make sure WooCommerce is installed and active.
5. Customize your store using the plugin's settings.

== Frequently Asked Questions ==

= Do I need to know coding to use this plugin? =
No, this plugin is designed for non-developers. All features can be toggled via the user interface.

= Will this plugin work without WooCommerce? =
No, WooCommerce is a required dependency for this plugin.
