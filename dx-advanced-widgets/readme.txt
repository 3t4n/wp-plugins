Collection of advanced features of the widget. 小工具高级功能集合。

== Description ==

1. Custom Category articles, and sort 自定义分类文章以及排序
2. display the article thumbnail 显示文章缩略图功能
3. flash show. 显示flash功能


详情：[http://www.daxiawp.com/dx-advanced-widgets.html](http://www.daxiawp.com/dx-advanced-widgets.html)

== Installation ==

可以通过以下两种方法的其中一种来安装DX-Advanced-Widgets插件：

1. 将下载的文件解压缩，然后将`DX-Advanced-Widgets`文件夹 上传到 `/wp-content/plugins/`目录，在插件后台启用

2. 直接在后台-安装插件，搜索'DX-Advanced-Widgets'，按照提示安装启用
