Displays a diwali countdown in your theme's widget area.



== Description ==

Diwali Countdown is a widget that displays Diwali festival countdown. 



== Installation ==



1. Upload `Diwali Countdown.zip` to `/wp-content/plugins/` directory
2. Activate the plugin through 'Plugins' menu in WordPress
3. Visit Appearance-> Widgets screens
4. Drag the Diwali Countdown widget to your widget area.
