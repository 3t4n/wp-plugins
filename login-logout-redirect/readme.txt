A simple WordPress plugin that redirects users after login/logout.

== Description ==

The Login Logout Redirect plugin helps you manage user redirection after login or logout. You can set a custom URL or select a specific page on your website. Additionally, this plugin tracks user login time and displays it in the admin user table. The login tracking feature is enabled by default but can be disabled via the settings.

## Features##

Redirect users to a specific URL or page after login.

Redirect users to a specific URL or page after logout.

Option to use a custom URL or choose from existing pages.


##Settings Options##

The plugin adds a settings page under Settings > Redirect Options where you can configure:

Login Redirect: Set a custom URL or select a page to redirect users after login.

Logout Redirect: Set a custom URL or select a page to redirect users after logout.

== Installation ==

Upload the plugin files to the /wp-content/plugins/login-logout-redirect directory, or install the plugin through the WordPress plugins screen directly.

Activate the plugin through the 'Plugins' screen in WordPress.

Go to Settings > Redirect Options to configure the plugin.

== Frequently Asked Questions ==

= How do I set up redirection after login and logout?=

Go to Settings > Redirect Options and provide the URL or select a page for login and logout redirects.

= How do I disable the user login time tracking?=

Under Settings > Redirect Options, uncheck the Enable Login User Time Tracking checkbox to disable this feature.
