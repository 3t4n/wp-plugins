== Installation ==
1.) Upload the .zip file
2.) Install and acivate the plugin
3.) Go to the page "Disk Space" at the Dashboard
4.) Enter your maximal avaible space and save the settings
5.) (optional) Add the widget to publish your space state

== Description ==
DiskSpace is a simple plugin for WordPress which showsyour actually disk space state at your dashboard.

== Upgrade notice ==
I try to upgrade DiskSpace for every WordPress version without problems at the update.
Deactivate DiskSpace on every major or minor update(*.*
