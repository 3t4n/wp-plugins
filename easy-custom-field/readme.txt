Automatically adds form element(s) in Write Post panel, which act as a easy custom field(s)

== Description ==

This plugin gives administrator a complete control for building there own custom fields in separate box in more flexible way. It is a replacement of your wordpress default custom field. Administrator can easily build a list of custom fields using Drag and Drop feature. The created list of custom fields will automatically show up in the Write Post page.

== Installation ==

1. Download "Easy Custom Fields" plugin.
1. Open /wp-content/plugins folder at your web server.
1. Upload the folder "Easy Custom Fields" there.
1. Goto Plugins page in your wordpress back office.
1. Activate "Easy Custom Fields" plugin.
1. Go to Settings >> Easy Custom Fields for modifying the settings.

Note: This plugin will require one time free registration.

== How to use it ==

* Go to Settings >> Easy Custom Fields
* Build custom fields using drag and drop feature. Drag the required fields from left hand side and drop them to right hand side box, enter the desired values and save. In the right hand side box you can also move these fields up and down by dragging with mouse.
* In write post section, enter the custom fields values under "Easy Custom Fields".
