A small plugin to hide UpdraftPlus related "news" from the admin dashboard.

== Description ==

Some administrators that white-label their maintenance service may wish to hide UpdraftPlus "news" from appearing on the admin dashboard.

== Installation ==

Only install/activate this plugin if UpdraftPlus is installed and activated.

1. Upload the plugin to the `${WP_CONTENT_DIR}/plugins/` directory
1. Activate the plugin through the 'Plugins' screen in WordPress
