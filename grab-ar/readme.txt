This plugin allows you to add the GRAB AR button to your WordPress site for a unique Augmented Reality experience for any Images on a page.

== Description ==

= Easily Insert the GRAB AR Code into your WordPress site =

The GRAB AR Plugin is a simple plugin that lets you insert the GRAB AR button into your WordPress site / online store. This compliments the GRAB AR Mobile App and allows you to view any Image / Product on your site pages in Augmented Reality. 

With GRAB AR you will be able to view any Image in Augmented Reality and visualise how products look in any environment that you choose using your Mobile Phone. 

Fill the Imagination Gap. See how products look in your chosen environment.

[youtube https://youtu.be/XEZV_RW7j1A]


= Features of GRAB AR Button plugin =

* Quick and simple to install 
* No need to edit your theme files
* GRAB any Image from your site pages and view in Augmented Reality

== Installation ==

1. Install GRAB AR Button plugin by uploading the `grabar` directory to the `/wp-content/plugins/` directory. (See instructions on <a href="http://www.wpbeginner.com/beginners-guide/step-by-step-guide-to-install-a-wordpress-plugin-for-beginners/" rel="friend">how to install a WordPress plugin</a>.)
2. Activate GRAB AR through the `Plugins` menu in WordPress.
3. Edit your settings by going to the `Settings > GRAB AR Settings` menu.

== Frequently Asked Questions ==

= How can I add the GRAB AR button to my site? =

1. Check the "Insert Automatically on all pages" option above and include css to position the button
2. Use the code provided in 'Settings'->'GRAB AR Button Settings' to insert into any html area
