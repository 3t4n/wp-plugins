Create temporary login links to access your site without a password. Manage user or guest access with custom expiration times or login limits.

== Description ==

Login Links allows you to create temporary, password-less login links for users or guest accounts. These links can be configured to expire either after a certain period of time or after a set number of successful logins, offering flexibility and security for managing access.

This is especially useful for site administrators, support teams, clients, or guest users who need temporary access to the site without requiring a username and password.

Key Features:

Generate temporary login links for both existing users and temporary users.
Customizable expiration based on time or number of logins.
Create and manage multiple temporary links for different users.
No passwords required – login via the secure link.
Prevent unauthorized access by automatically expiring the links after use.

== Main Features ==

Temporary login links: Quickly create links to log in as a specific user or temporary user.
Set expiration time: Customize the link’s expiration time (hours, days, etc.).
Login limits: Define how many times the link can be successfully used.
Secure authentication: No password needed, reducing exposure to brute force attacks.
Multiple links: Generate multiple login links for different users or access scenarios.

== Installation ==

Upload the temporary-login-links folder to the /wp-content/plugins/ directory.
Activate the plugin through the 'Plugins' menu in WordPress.
Navigate to Temporary Login Links in the WordPress admin dashboard.
Create temporary login links by selecting the user and configuring the expiration time and login limit.

== Frequently Asked Questions ==

= What is a temporary login link? =

A temporary login link allows users to log in without a password, and you can set the link to expire after a specific period of time or after a certain number of successful logins.

= Can I create multiple login links for the same user? =

Yes, you can generate multiple temporary login links for the same user, each with its own expiration time or login limit.

= How do I prevent the link from being used after it expires? =

The plugin automatically invalidates the link after it reaches its expiration time or the maximum number of allowed logins is reached.

= Can temporary login links be created for guest or temporary users? =

Yes! You can generate login links for temporary users without needing to create permanent accounts.

= Is the plugin secure? =

Yes. Each login link is unique, and the absence of a password reduces the risk of brute force attacks. The links automatically expire after the specified time or login count.
