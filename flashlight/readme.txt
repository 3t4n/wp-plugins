== Description ==

= RUS =

**Flashlight** - плагин, позволяющий с помощью виджета включать и выключать фонарик на сайте.

= ENG = 

**Flashlight** - plugin to toggle a flashlight on and off.

Author: [Flaeron](http://wp-lessons.com/o-avtore "Flaeron")

== Installation ==

1. Разархивируйте и закачайте папку плагина в 'wp-content/plugins/'
2. Зайдите в административное меню WordPress
3. Активируйте плагин
4. Зайдите в 'Внешний вид' > Виджеты
5. Добавьте виджет 'Flashlight' на сайдбар
