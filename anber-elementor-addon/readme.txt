== Description ==

Anber Elementor Addon empowers you to create stunning and dynamic websites using Elementor. It extends your design toolkit with a collection of customizable widgets, including:

1. **Anber Banner/Hero Banner**: Create an eye-catching hero section with smooth scrolling and captivating visuals.
2. **Anber Slider/Carousel**: Display your content in a responsive and customizable carousel format.
3. **Anber Post Carousel**: Showcase your posts in an engaging and interactive carousel.
4. **Video Popup**: Display videos in a lightbox for a seamless and immersive user experience.

== Installation ==
1. Upload the `anber-elementor-addon` directory to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

== Frequently Asked Questions ==

= How do I use the Addon widgets? =
After activation, search for "Anber Hero Slider" in Elementor's widget panel under the "Anber Addon" category. Drag and drop it onto your page, customize the settings, and add your images or video content. Refer to Elementor's documentation for further guidance on using widgets.

= Are there additional configuration options for the Carousel widget? =
Yes! You can customize the number of slides displayed, navigation settings, autoplay behavior, and more within the widget's settings panel.
