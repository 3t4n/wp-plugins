Plugin ES Custom Fields Interface Versione 3.10 10/12/2009

Questo plugin serve per inserire campi personalizzati negli articoli e nelle pagine.

Tramite il file config.txt vengono configurati i campi personalizzati (tipo, nome e altri parametri).

type fieldset checkbox radio select textarea textfield
datefield 		filefield
imagefield

[gruppo7close] ; Chiudi gruppo di campi 		[campo76] ; Nome del campo, scritto tra parentesi quadre
page page=post ; campo visibile solo negli articoli
page=page ; campo visibile solo nelle pagine
; omesso campo visibile negli articoli e nelle pagine
label label=Gruppo genio
; omesso Chiudi gruppo di campi		 label=Campo geniale 76 ; Etichetta visibile del campo

; Testo di specificazione		 help=Digita un testo
; Testo di aiuto

required=0 ; (oppure omesso) campo facoltativo

values=categories ; elenca categorie ad albero
values=tags ; elenca tags
