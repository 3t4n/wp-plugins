# Dadevarzan beaver builder custom modules

[Beaver builder](https://www.wpbeaverbuilder.com/) is one of the best page builder of WordPress.
[dadevarzan co.](http://www.dadevarzan.com/) is using this plugin to develop WordPress blog pages. 

In this repository we publish our beaver builder custom modules for community and populate saved layouts, templates, rows and modules.

## Our modules ##
- [Yoast Breadcrumbs](https://kb.yoast.com/kb/implement-wordpress-seo-breadcrumbs/)
- Display Date and Time.
- Display Dadevarzan Powered By.
- Added custom field type beaver builder Templates to ACF fields in admin.
