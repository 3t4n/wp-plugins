== Description ==

[Beaver builder](https://www.wpbeaverbuilder.com/) is one of the best WordPress page builders.
[dadevarzan co.](http://www.dadevarzan.com/) is using Beaver builder to develop WordPress websites.
[On Scroll Add CSS CLASS](https://css-tricks.com/scroll-fix-content/#article-header-id-3)

In this repository we publishing our beaver builder custom modules and populating our ready to use saved beaver builder **layouts, templates, rows and modules**.

= Our custom modules: =

1. [Yoast Breadcrumbs](https://kb.yoast.com/kb/implement-wordpress-seo-breadcrumbs/)
2. Displaying current Date and Time.
3. Adding/removeing CSS class based on vertical scroll.
4. Displaying Iran SVG Map with province path.
5. Dadevarzan.com Power by module.

And Added custom field type beaver builder Templates to ACF fields in admin.

== Installation ==
1. Install Dadevarzan beaver builder custom modules either via the WordPress.org plugin repository or by uploading the files to your server. (See instructions on <a href="http://www.wpbeginner.com/beginners-guide/step-by-step-guide-to-install-a-wordpress-plugin-for-beginners/" rel="friend">how to install a WordPress plugin</a>)
2. Activate Dadevarzan beaver builder custom modules.
