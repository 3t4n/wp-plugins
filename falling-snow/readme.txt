This plugin adds a falling snow effect to your blog.

== Description ==

== Installation ==

* Download falling-snow-1.0.zip to your /wp-content/plugins/ directory.
* Unzip falling-snow-1.0.zip file.
* Go to Admin - Plugins page. Activate Falling Snow plugin.
* That's it.
