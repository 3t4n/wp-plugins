Archisketch is a 3D interior CRM using AR/VR, 2D/3D floor plans, and render images to attract visitors and support online businesses.

== Description ==

**✅ To use this app, you will need an Archisketch Enterprise Admin Account.**
If you don't have an account, please contact us through [🔗 Enterprise Trial Page](https://www.archisketch.com/en/enterprisetrial) or [🔗 Archisketch ChannelTalk](https://archisketch.channel.io/).

-

Archisketch is a 3D interior CRM enabling businesses to integrate AR/VR, 2D/3D floor plans, and realistic render images into their websites. It enhances visitor engagement and supports online businesses with interactive design tools.

== Frequently Asked Questions ==  

**Q: I want to try Archisketch App. How can I use it?**  
A: If you are an Archisketch Enterprise Member, you can easily integrate and use Archisketch without any developer support after installing the app.

To become an Archisketch Enterprise Member, please contact the Archisketch team for registration.
Follow the steps below to install the application:

1️⃣ **Install the app**
Click the 'Install' button at the top of this page to proceed with the app installation.

2️⃣ **Check the App Integration Status**
Clicking the 'Check Integration' button will redirect you to the Archisketch connector page, where you can control whether the Archisketch dashboard is connected or not.

3️⃣ **Complete the integration**
Follow the integration guide to finish the process. an Archisketch floating button will appear on your website. The installation process is optimized for WordPress, so there's no additional wait time or need for developer assistance during integration.  

**Q: How can I sign up for an Archisketch Enterprise Membership?**  
A: You can sign up for an Archisketch Enterprise Membership by contacting the Archisketch team.
Once the registration is complete, you will be provided with **1) an enterprise member account** and **2) an enterprise service domain**.  

**Q: Can customers who enter the website after integration also use Archisketch?**  
A: Yes, anyone can use Archisketch by clicking the Archisketch floating button on the website.
*If you don't want to expose Archisketch to users, you can enable the "Hide Button" feature in the **[Integration > Web Button Settings]** section of the admin page.

**Q: Do I need 3D modeling data to use Archisketch?**  
A: No, you can use Archisketch without 3D modeling data since we provide a basic library of 3D models. However, if you wish to display and use your products, you may need the corresponding 3D modeling data.
You can create the 3D models yourself and upload them to Archisketch, or you can request modeling outsourcing by contacting us through the Chat function on the Archisketch website.
