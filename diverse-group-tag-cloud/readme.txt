A plugin that builds a tag cloud using content from one or more blogs or other websites that provide an RSS feed.

== Description ==

The [Diverse Group Tag Cloud][1] plugin is designed to construct a tag cloud using a diverse group of information sources such as a list of blogs. It is most useful on blogs that have a number of contributors.

The plugin is currently being used by the Libraries Interact blog to provide the [THALI-Tags][2] page.

More information is available on the [Diverse Group Tag Cloud][1] plugin homepage.

 [1]: http://techxplorer.com/projects/diverse-group-tag-cloud "Plugin homepage"
 [2]: http://librariesinteract.info/thali-tags/ "Direct link to the page"
	
== Installation ==

Extract the zip file and just drop the contents in the wp-content/plugins/ directory of your WordPress installation and then activate the Plugin from Plugins page.

Once activated use the settings page to configure the plugin and the Links Manager to add links to the content sources. More detailed information is avaiable via the [Diverse Group Tag Cloud][1] plugin homepage.

 [1]: http://techxplorer.com/projects/diverse-group-tag-cloud "Plugin homepage"
