This plugin adds support for WP Job Manager single post type in Elementor Pro template's display conditions.

== Description ==

This plugin allows users to style the single post template of WP Job Manager plugin using Elementor Pro, as it does not show in the Display Options condition of Elementor template by default.

== Frequently Asked Questions ==

= Does it work with Elementor free version? =

No. It only works with Elementor Pro, as you cannot create a single post type template in Elementor free version.
