== Description ==

Merge posts, pages and custom posts

= Features =
* Merge 3 posts into one
* Merge 3 pages into one

= History & Raison d'être =

While creating the new website for (AOC)[http://www.aoc.cat] we did an import from old contents. However, due to its content structure, each tab was a diferent page.

We needed something to allow us to merge many pages into just one. As we didn't find a plugin to do it, we decided to build our own.

== Installation ==

1. Use plugin usual installation process.

== Frequently Asked Questions ==
To use the plugin, you have to enter Tools > Merge Posts
