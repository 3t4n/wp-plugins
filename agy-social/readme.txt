Adds a Whatsapp icon to the website footer.

== Description ==

AGY Social adds a Whatsapp icon to your website footer, allowing visitors to contact you directly via Whatsapp. The Whatsapp number can be easily configured via the WordPress admin panel on the bottom left side.
== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/agy-social` directory or install the plugin directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to 'AGY Social' in the admin panel menu, activate the plugin, enter your WhatsApp number with the country code and area code and choose which icon you like best and click save.

== FAQ ==

= How do I set up my AGY Social number? =
After activating the plugin, go to 'AGY Social' in the admin panel menu and enter the Whatsapp number in international format (country code followed by the number).

= The AGY Social icon does not appear in the footer, what do I do? =
Make sure you have entered a valid AGY Social number in international format. Also check if your theme supports footer hooks. Also make sure it is enabled.
