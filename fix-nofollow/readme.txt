Simple plugin to fix the latest Google algorithm update. It will add `rel=&quot;nofollow&quot;` and `target=&quot;_blank&quot;` to all EXTERNAL links only. This is good if you have previously sold links or have guest blog posts. If Webmaster Tools gives you a message "Unnatural outbound links", this will help you fix it and quickly!

== Description ==

With Google's latest alorithm update, sites are now penalised for either offering paid backlinks or guest posts. This plugin simply fixes this by adhering to Google's recommended action:

Recommended action<br>
Identify paid or otherwise inorganic links by using rel="nofollow" or redirecting to an intermediate page that is blocked by robots.txt.<br />
Remove any problematic links from your site.<br />
When you're satisfied that your site follows Google's Webmaster Guidelines, submit a reconsideration request.<br />
For an updated list of manual actions currently applied to your site, visit the Manual Actions page. If no manual actions are listed, there is no longer a need to file a reconsideration request.

= Feature =
* Adds `rel="nofollow"` and `target="_blank"` to all EXTERNAL links only.
* Internal links stay as they are.
* Next version will see the option to exclude links.

== Installation ==

1. Download the latest zip file and extract the 'fix-nofollow' directory.
2. Upload it to your '/wp-content/plugins/' directory.
3. Activate 'Fix noFollow' on the 'Plugins' menu in WordPress.
