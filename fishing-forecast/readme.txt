== Description ==

This is a daily fishing forecast widget. 
The widget show 5 day fishing forecast (best fish bite times) for the selected city. 
The widget using http://preweather.com/fishing-forecast/ API. 
The content will be pulled from local gif file.

More about plugin: http://preweather.com/fishing-forecast/wordpress-plugin/

== Installation ==

1. Unzip "fishing-forecast.zip" and upload the contained files to the "/wp-content/plugins/" directory
2. Activate the plugin through the "Plugins" menu in WordPress
3. Install "Fishing Forecast" through the WordPress admin menu of Appearance or Design and then widgets.
4. add city ID: In order to get the city ID you need to open a page with a general fishing forecast for your city and click on the link: "Free Forecast Widget - name of your city".
