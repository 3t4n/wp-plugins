Adds an admin notes block to post and page editing screens with formatted text support and user notifications.

== Description ==

**AdminNotes** allows administrators and editors to add formatted notes to posts and pages. These notes can serve as reminders, tasks, or recommendations for content editors. Additionally, when enabled, users are notified to read these admin notes before editing the content.

**Features:**
- Add formatted notes using a rich text editor in both Classic and Gutenberg editors.
- Display a notification message to users when editing a post or page if admin notes are present.
- Option to enable or disable the notification on a per-post/page basis.

== Installation ==

1. Upload the `admin-notes` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the post or page editing screen to add admin notes and configure notifications.

== Frequently Asked Questions ==

= How do I add admin notes to a post or page? =

After activating the plugin, edit a post or page. Scroll down to the **Admin Notes** meta box where you can add your notes using the rich text editor.

= How do I enable the notification message for a post or page? =

In the **Admin Notes** meta box, check the box labeled "Show admin notes notification when editing" to enable the notification message for that specific post or page.
