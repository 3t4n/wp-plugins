Automatically adds a backlink to your site when you copy text from it.

== Description ==

The "Add Backlink or Copy Protection" plugin automatically appends a backlink to your site when users copy text from it. 

== Installation ==


1. Upload the plugin files to the `/wp-content/plugins/add-backlink-or-copy-protection` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.

3. Enjoy automatic backlinking for copied content.

== Frequently Asked Questions ==

= Is this plugin compatible with the latest version of WordPress? =

Yes, the plugin has been tested with WordPress version 6.7.1.
