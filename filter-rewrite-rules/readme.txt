Filter rewrite rules for performance problems on post/pages with permalinks

== Description ==
Filter rewrite rules for better performance on post/pages with active permalinks; can help you to load faster backend and frontend.

= No longer maintained =
This plugin is no longer maintained. It is actively tested up to version 3.4-Beta3.

== Installation ==
= Requirements =
* WordPress version 2.9 and later (see tested up to)
* PHP 5.2

= Installation =
1. Unpack the download-package
1. Upload the folder and all folder and files includes this to the `/wp-content/plugins/` directory
1. Activate the plugin through the 'Plugins' menu in WordPress
1. Thats all
