== Description ==

The AI Widget plugin allows you to seamlessly add AI-powered widgets to your WordPress site. Customize settings to meet your specific requirements and enhance user interaction with advanced AI capabilities.

== External Services ==

The AI Widget plugin connects to the ChatBotKit service to provide AI-powered widget capabilities on your website.

- **Service Name**: ChatBotKit
- **Purpose**: To enhance user interaction on your site through AI-driven chat and widget features.
- **Data Sent on load**: The plugin sends the widget ID configured in the settings to ChatBotKit servers to retrieve the appropriate widget. No personal data or other user information is sent through this process.
- **Data Sent when used**: Data is transmitted when the widget is used by the website visitor to answer questions and perform tasks as per the widget configuration.
- **Terms of Service**: [ChatBotKit Terms of Service](https://chatbotkit.com/legal/terms)
- **Privacy Policy**: [ChatBotKit Privacy Policy](https://chatbotkit.com/legal/privacy)

== Installation ==

= Standard Installation =

This method is the easiest and recommended for most users.

1. Go to the WordPress Plugin Directory in your WordPress admin area.
2. Search for "AI Widget".
3. Click "Install Now" and then activate the plugin.
4. Configure the plugin through the Settings -> AI Widget screen to personalize your experience.
5. Add your Widget ID to start enhancing your website with AI features.

= Manual Installation =

If you prefer to handle the files directly, follow these steps for a manual setup.

1. Download the plugin file from the plugin repository.
2. Use an FTP client to upload the plugin files to the `/wp-content/plugins/ai-widget` directory on your server.
3. Navigate to the 'Plugins' screen in WordPress and activate the plugin.
4. Access the Settings -> AI Widget screen to configure the plugin according to your needs.
5. Enter your Widget ID to enable AI functionality on your site.

== Frequently Asked Questions ==

= How do I obtain a widget ID? =

You can obtain a widget ID by visiting [ChatBotKit](https://chatbotkit.com/new) and creating a new widget.

= Why isn't my widget showing? =

Ensure you have entered the correct widget ID on the settings page. If the problem persists, check the console for errors.
