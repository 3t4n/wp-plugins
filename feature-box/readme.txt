== Description ==

The <strong>Feature Box Block</strong> is a great way to show important key features in <strong>the Gutenberg editor</strong>. You can have large background image, with colorful content box to displayed your important information. With featured box block, you can display your featured image with beautiful info box and call to action button.

= Plugin Key Features =
* Background Image size
* Content positioning
* Ability to add Title, Description and CTA
* Spacing options
* Separator Customization
* Color and Typography options for each element of the block
* Easy Call To Action

== Installation ==
<strong>Modern Way</strong>
1. Go to the WordPress Block/Gutenberg Editor
2. Search For “feature box”.
3. Install in 1-click

<strong>Old Way</strong>
1. Upload the plugin files to the `/wp-content/plugins/feature-box` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the 'Plugins' screen in WordPress
