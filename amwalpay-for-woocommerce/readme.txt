== Description ==  
### Accept Secure Payments with AmwalPay for WooCommerce  
AmwalPay for WooCommerce allows merchants to accept online payments via **credit/debit cards and digital wallets** using the **Amwal Payment Gateway**.  

### Why Choose AmwalPay?  
✅ **Seamless 3D Secure (3DS) OTP Authentication**  
✅ **PCI-DSS Compliant & Highly Secure Transactions**  
✅ **High Payment Success Rates & Fast Settlements**  
✅ **Tokenization for Secure Card Storage**  
✅ **Supports Mobile-First Checkout Experience**  

With **AmwalPay**, businesses can **process transactions efficiently** while providing customers with a **smooth and secure** checkout experience.  

**Learn More:** [AmwalPay Official Website](https://www.amwal-pay.com/)

== Installation ==  
### Automatic Installation  
1. Log in to your **WordPress Admin Dashboard**.  
2. Navigate to **Plugins > Add New**.  
3. Search for **"AmwalPay for WooCommerce"**.  
4. Click **Install Now**, then **Activate** the plugin.  
5. Go to **WooCommerce > Settings > Payments** and configure **AmwalPay Settings**.  

### Manual Installation  
1. Download the plugin as a `.zip` file.  
2. Go to **Plugins > Add New > Upload Plugin**.  
3. Upload the `.zip` file and click **Install Now**.  
4. Activate the plugin and configure the settings under **WooCommerce > Settings > Payments**.

== Configuration ==  
To enable AmwalPay, you need the following details from **AmwalPay**:  
🔹 **Merchant ID**  
🔹 **Terminal ID**  
🔹 **Secret Key**  

Enter these credentials under **WooCommerce > Settings > Payments > AmwalPay** to start processing payments.

== Frequently Asked Questions ==  
### 1. How do I get AmwalPay API credentials?  
Sign up at [AmwalPay](https://www.amwal-pay.com/) and and our sales team will reach out to you. Once contract is signed, we'll send you your Merchant ID, Terminal ID, and Secure Key.  

### 2. Is AmwalPay secure?  
Yes, AmwalPay is **PCI-DSS compliant** and supports **3D Secure authentication** for safe transactions.  

### 3. What payment methods does AmwalPay support?  
AmwalPay supports **credit/debit cards**.  

### 4. Does this plugin support test mode?  
Yes, you can enable **sandbox mode** using the **UAT API** for testing before going live.
