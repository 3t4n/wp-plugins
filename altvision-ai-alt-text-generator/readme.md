== Description ==

AltVision automatically generate precise alt text for your images by analyzing both the image and its surrounding context. The plugin considers headings, paragraphs, and captions near the image to create highly relevant descriptions. Stop spending hours writing manual descriptions - let AI do the heavy lifting!

⭐ Key Features

* 🎯 **One-click Generation**: Generate intelligent alt text instantly
* 🔌 **WordPress Ready**: Seamless WordPress and Gutenberg integration
* 🎨 **Format Support**: Works with JPG, PNG, WebP, and more
* 🔒 **Accessibility First**: WCAG 2.1 compliance support

🏆 Premium Features

== Installation ==

1. Upload plugin to `/wp-content/plugins/altvision-ai-alt-text-generator`
2. Activate via WordPress Plugins screen
3. Configure in Settings->AltVision

## 🔧 Requirements

* WordPress 5.0 or higher
* PHP 7.4 or higher

== Frequently Asked Questions ==

= How does the AI generate alt text? =

The plugin uses OpenAI API to analyze both images and their surrounding content. It examines adjacent headings, paragraphs, and captions to understand the context, resulting in more meaningful and relevant descriptions that enhance both accessibility and SEO.

= Is there a limit to how many images I can process? =

Free users can process 10 images per day. Premium users get unlimited processing.

= Can I edit the generated alt text? =

Yes! While our AI is highly accurate, you can always review and modify the generated alt text to better match your needs.

= Do I need an API key to use the plugin? =

No API key is needed for the free version. Premium users receive an API key upon subscription activation.

= What image formats are supported? =

We support all common web formats including JPG, PNG, WebP, GIF, and AVIF.

= Can I bulk process existing images in my media library? =

Premium users can process their entire media library with our bulk processing feature. Free users can process images one at a time.

= Does it work with CDN-hosted images? =

Yes, AltVision works with all major CDN providers and can process any publicly accessible image URL.

= What languages are supported? =

Currently, we generate alt text in English, with plans to add more languages soon. Premium users get early access to new language support.

= Can I customize the AI's output style? =

Premium users can adjust the AI's output style to match their brand voice and preferred level of detail.
