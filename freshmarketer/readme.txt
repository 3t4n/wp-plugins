This plugin connects with Freshmarketer, a simple and powerful tool to optimize your Wordpress site using A/B testing, heatmaps and other optimization tools.

== Description ==
Freshmarketer is an all-in-one conversion rate optimization platform. Freshmarketer is an easier way for to improve your website through A/B testing. Create an experiment in minutes with our easy-to-use visual interface with absolutely no coding or engineering required. Convert your website visitors into customers and earn more revenue today!

== Installation ==
Extract the zip file and just drop the contents in the wp-content/plugins/ directory of your WordPress installation and then activate the Plugin from Plugins page.
