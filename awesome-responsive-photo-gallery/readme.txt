### Why Use This Plugin?
WordPress has a built-in gallery feature, but it is quite basic. It doesn't include a lightbox option, which means when users click on an image, it opens in a new page instead of a popup. This can make browsing your images less user-friendly and slower.

Our plugin improves the default WordPress gallery by turning it into a modern, interactive lightbox gallery. Once installed, every gallery you create will have a smooth, professional look. Visitors can click on any image to view it in a popup with navigation options, making your gallery more attractive and easier to use.

### How Does It Help You?
1. **Automatic Upgrade:** After installing the plugin, it replaces the default gallery with the upgraded lightbox version. No extra setup needed.
2. **Better User Experience:** Visitors can quickly browse through images in a popup without leaving the page.
3. **Professional Look:** Makes your gallery feel premium and enhances your site's design.

This plugin works automatically, saving you time and effort while giving your gallery a polished, modern appearance.

== Usage ==

1. After activating the plugin, navigate to **Awesome Gallery** in your WordPress admin panel.
2. Navigate to **Pages >> Add New** and click on **Add Media** to open the media uploader.
3. Click on **Create Gallery** and select **Upload Files** if you don’t have any images
4. Upload your photos and after completing upload click on **Create a New Gallery** button
5. In the right side enter image Title, Alt Text, Description and Video URL (if you want)
6. Click on **Insert Gallery** button
7. In the gallery shortcode insert your desired **Gallery ID** (depends on how you want to show your gallery), like [gallery **id="1"** ids="114,115,112,113,110"]
8. Publish your page and click **View Page** to see your awesome gallery 🙂.
9. To create another gallery, use an another unique ID. Example: [gallery id="1" ids="506,505,502,503"] or [gallery id="2" ids="506,505,502,503"]
10. Access the **Help Page** under the plugin menu for detailed instructions.

== Installation ==

**Awesome Responsive Photo Gallery** plugin can be installed in two convenient ways: manually or directly from the WordPress plugin directory.

= Manual Installation: =
1. Log in to your WordPress admin dashboard.
2. Navigate to **Plugins** in the left menu and click **Add New**.
3. Click **Upload Plugin** and choose the **awesome-responsive-photo-gallery.1.2.zip** file. Click **Install Now**.
4. Once installed, activate the plugin to enable its features.

= Installation from WordPress Plugin Directory: =
1. Log in to your WordPress admin dashboard.
2. In the left menu, click **Plugins**, then select **Add New**.
3. In the search field, type **Awesome Responsive Photo Gallery Realwebcare** and press Enter.
4. Locate the plugin in the search results and click the **Install Now** button.
5. After installation, activate the plugin.


== Frequently Asked Questions ==

= How do I create a gallery with this plugin? =
Creating a gallery is simple:
1. Go to **Pages > Add New** or edit an existing page.
2. Click **Add Media** and select **Create Gallery**.
3. Upload images or select existing ones, then insert the gallery shortcode.
4. Use the plugin settings or assign a unique Gallery ID to customize your gallery.

= Does the plugin support videos? =
Yes, the plugin supports YouTube, Vimeo, and HTML5 videos. Simply add the video URL in the **Video URL** field under **Attachment details** while creating the gallery.

= Can I use multiple galleries on the same page? =
Absolutely! You can create unlimited galleries by assigning unique Gallery IDs for each gallery.

= What are the supported lightbox scripts? =
The plugin supports three responsive lightbox scripts:
1. **lightGallery**
2. **Lightcase**
3. **jGallery**

You can choose your preferred lightbox script from the plugin settings.

= Is the plugin compatible with the Block Editor (Gutenberg)? =
Yes, the plugin integrates seamlessly with both the Block Editor and Classic Editor. It allows you to dynamically insert Gallery IDs directly into your post or page.

= How do I customize the appearance of my gallery? =
You can customize the gallery by:
1. Choosing from five image sizes: Thumbnail, Medium, Large, Full Size, or Custom.
2. Adjusting thumbnail borders, shadows, and hover effects in the plugin settings.

= Is the plugin fully responsive? =
Yes, the plugin is designed to adapt to all screen sizes, making your galleries look great on any device.

= Does the plugin support social sharing? =
Yes, the lightbox includes social sharing options for platforms like Facebook, Twitter, and Pinterest.

= What security measures are implemented? =
The plugin is built with modern WordPress standards, including sanitization, validation, escaping, and nonce verification, ensuring secure operation.

For support:
