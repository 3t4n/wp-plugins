FooterComments adds html comments to your wordpress footer

== Description ==

FooterComments is a WordPress plugin that provide the user to add html comments in the wordpress footer.

== Installation ==

1. Copy FooterComments directory to your `wp-content/plugins` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Under the 'Plugins' menu you will see 'Footercomments'.
4. Click on 'FooterComments' and you will see footer comments textarea.
5. write the text you want as your wordpress footer comments and then click save.


== Frequently Asked Questions ==
= what kind of content can i put on my footer comments? =

Any alphanumerical character except --> which will give unexpected 
results.
