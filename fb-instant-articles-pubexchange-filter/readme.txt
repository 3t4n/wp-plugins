Extend Wordpress's plugin for Instant Articles for Facebook to include PubExchange click tracking.

== Description ==

This plugin adds a filter to Wordpress' Instant Articles plugin so that clicks can be recorded by PubExchange. Instant Articles for Facebook is a new way for publishers to distribute fast, interactive stories on Facebook. Instant Articles are preloaded in the Facebook mobile app so they load instantly.

For this plugin to work properly, you must also install the official [Wordpress plugin](https://wordpress.org/plugins/fb-instant-articles/). You must also have an account with PubExchange, but NOT have installed the [PubExchange module plugin](https://wordpress.org/plugins/pubexchange/) (version 2.0.2 or later), since that plugin already adds the filter.

Developers: please note that since the Wordpress plugin is still in the early stages and may experience changes, this plugin may change frequently as well.

== Installation ==

1. Upload the folder to the `/wp-content/plugins/` directory
1. Activate the plugin through the 'Plugins' menu in WordPress
