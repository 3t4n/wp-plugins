WordPress integration for Booked Scheduler

== Description ==
Easily embed Booked Scheduler calendars and reservation workflows directly within WordPress using simple Shortcodes.

This plugin requires a Booked Cloud subscription or a Booked On-Prem installation.

== Installation ==
1. Upload the entire `booked` directory to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Update configuration settings from the Booked Scheduler menu item
4. Add a Booked Shortcode to any Page or Post

== Frequently Asked Questions ==
= Does this plugin require a standalone Booked Scheduler instance?
Yes, this plugin requires a [Booked Cloud](https://www.bookedscheduler.com/free-trial/) subscription or a [Booked On-Prem](https://www.bookedscheduler.com/licensing/) installation.

= Where can I find more documentation?
