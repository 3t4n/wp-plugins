== Description ==

Simple Plugin for easy and quick hiding Wordpress All Public Posts/CPT Reply/Comment Forms.

Please post bugs here: https://bitbucket.org/allouise/easy-hide-form/issues

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/plugin-name` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Easy Hide Form Settings page to configure the plugin
