All Content Copy Protection helps you protect your website content by disabling text selection, copying, right-clicking, and other actions.

== Description ==

The **All Content Copy Protection** plugin allows you to easily protect your website content from being copied by visitors. It provides various protective measures that can be enabled or disabled via an intuitive admin interface.

Key features:
* Disable right-click context menu.
* Disable text selection.
* Disable drag-and-drop actions.
* Disable keyboard shortcuts like `Ctrl+C`, `Ctrl+V`, `Ctrl+U`, and others.
* Block Developer Tools (F12) and function keys.
* Fully customizable - choose which protections to enable.
* Protection applies only to guest users (logged-in users and administrators are excluded).

This plugin is lightweight and easy to use, ensuring your content stays safe without impacting website performance.

== Installation ==

1. Download the plugin and upload it to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **All Content Copy Protection** in the WordPress admin panel to configure protection settings.

== Frequently Asked Questions ==

= Does this plugin work for logged-in users? =
No, the protection is applied only to guest users. Logged-in users, including administrators, are not restricted by the plugin.

= Can I customize which protections to enable? =
Yes, the plugin offers a variety of protections that can be toggled individually in the settings.

= Does this plugin affect website performance? =
The plugin is designed to be lightweight and has minimal impact on performance.
