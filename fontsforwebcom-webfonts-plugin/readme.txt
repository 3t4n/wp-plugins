== Description ==

The simplest fonts plugin for wordpress! Look at screenshot to see how easy and fast that is! Select & apply instantly!

Plugin name has changed! Now download it at: http://wordpress.org/extend/plugins/font

Install, activate, In post editor Just click a new button with "F" and font mini-browser will appear.

This single image will explain everyting about [how to use this wordpress fonts plugin](http://wordpress.org/extend/plugins/fontsforwebcom-webfonts-plugin/screenshots/ "how to use this wordpres fonts plugin")

Now just select any word or sentence in post editor, click on any font in mini-browser and it will change instantly! You can even type with it from the end of selection.

It's that simple! Over 1000 fonts to choose and you can upload your fonts too!

Always read each font's readme to make sure you're not abusing any copyrights!

If you're happy or not please give some comment. It's very useful in detecting any bugs and introducing new features.

== Installation ==

Easy way
1. Go to your dashboard > plugin > add > upload
2. Choose downloaded plugin zip file and upload
3. Activate plugin

Alternative way
1. Unzip `WPFontsForWebwebfontsplugin.zip` to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to text editor
