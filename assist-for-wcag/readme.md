Assist For WCAG ensures accessibility by meeting WCAG 2.1/2.2 standards, offering tools to customize content display for improved usability and inclusivity.

## Description
Assist For WCAG empowers website owners to provide inclusive user experiences by meeting the latest accessibility standards (WCAG 2.1 and WCAG 2.2). This plugin enables website visitors to customize content presentation, enhancing readability and usability.
#### Demo: [https://wcag.dock.codes/#wcag-open](https://wcag.dock.codes/#wcag-open)

## Key Features
1. Color Adjustment:
   1. Invert colors for better visibility.
   2. Enhance contrast to make text and UI elements stand out.
2. Font Size Control:
   1. Enable text resizing to accommodate users with visual impairments.
3. Additional Accessibility Profiles:
   1. Profiles tailored to specific needs, such as users with ADHD, dyslexia, or visual challenges.
4. Dynamic Integration:
   1. Connects with the latest WCAG-compliant solutions via our API for seamless updates.


## How It Works
The plugin uses an external API to load and execute the latest accessibility solutions, ensuring compliance with evolving WCAG guidelines.

## API Endpoint
https://wcag.dock.codes/accessibility/{token}/start.js?t={timestamp}

## Why Use an API?
- Automatic Updates: No manual file updates are required.
- Rapid Compliance: Instant adaptation to changes in accessibility standards.
- Centralized Management: Continuous improvements and bug fixes delivered to all users simultaneously.

== Installation ==
- Download and install the plugin through the WordPress Dashboard.
- Navigate to the Settings section of the plugin.
- Enter your unique API token in the provided field.
- Save your settings and refresh your site to activate accessibility features.

## External Services

## Frequently Asked Questions

= Is the WCAG module free? =

For companies with less traffic and smaller requirements, we have prepared a free version of the module, which you can install yourself. For sites with higher traffic (>10 thousand impressions) or if your requirements are higher than what the free version of the module offers, we have prepared a more extensive version of the module. More about the plans in the tab [price list](https://wcag.dock.codes/en/#pricing).

= What kind of data is collected? =

We do not collect any personal information about users. The only information that is recorded by our server is the IP address of the network and the browser agent, which is used only for analytical purposes and monitoring the performance of the service. No data that identifies a user is collected or stored. We care about the privacy of our users and comply with applicable data protection laws.

= Can I use the local version of the script? =

No, our solution does not allow you to use the local version of the script. It runs on a SaaS (Software as a Service) license, which means that the script is hosted on our servers. This form allows the solution to be constantly updated, ensuring compliance with the latest regulations and standards, such as WCAG 2.1 and RODO. By using a local version, the user would risk a lack of updates and possible non-compliance with current regulations. In addition, central hosting allows for better security, monitoring of the script’s performance and quick technical support, which would not be possible with a local version.

= Do I need to hook up a credit card to use the free version? =

No, the free version does not require any payment information. You can use the full functionality of the free version without entering your credit card information.

= Can I customize the look of the widget for my project? =

Yes, the widget is fully customizable. You can adjust its color palette, change its default position on the page, and enable or disable individual options that you don’t need. In addition, if you want, you can create your own HTML widget, customize the selectors in the module’s configuration and integrate it into your site. See our documentation for more details.

= Can I install this solution on several sites at the same time? =

Yes, our solution allows you to install on multiple sites simultaneously. All you need to do is to specify all the domains you will use in the token configuration. This way you will be able to have the same solution implemented on different sites.

= Is the widget compliant with the latest version of WCAG? =

Yes, our solution is compliant with the latest versions of WCAG 2.1 and 2.2. The WCAG 2.1 guidelines include details on adapting pages to people with disabilities, while WCAG 2.2 extends them with additional recommendations and requirements. Our module meets all these requirements and ensures full compliance with current accessibility standards.

= Do I have to make any changes to the content of the site to take advantage of this solution? =

The module helps bring the site up to WCAG standards, but some problems, such as improper page structure, may require manual correction. The module alone will not solve such problems. If you encounter difficulties in adjusting the content of your site, our developers can help you. Contact us for support.

= Will the widget work with different languages? =

Yes, our solution supports many languages, including Czech, German, English, French, Italian, Polish, Slovak, Ukrainian, Spanish, Dutch, Norwegian, Hindi, Arabic, Kazakh and Kashubian. This makes it easy to customize a solution for your site, no matter what language it is in.
