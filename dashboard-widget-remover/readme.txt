Easily remove any/all of the default WordPress dashboard widgets for specific user role. Useful for multi-user blog.

== Description ==

Adds an options page for Administrators to choose which default WordPress dashboard widgets are available for which user role. very useful for multi-user blog.

== Installation ==
1. download and unzip the plugin folder
1. Upload `dashboard-widget-remover` folder to the `/wp-content/plugins/` directory.

1. Activate the plugin through the 'Plugins' menu in WordPress.

1. Go to Settings >> Dashboard Widget and check/unchek settings to display/hide dasboard widgets for specific user role
