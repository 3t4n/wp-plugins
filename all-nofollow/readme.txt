Adds `nofollow` to external and specified internal links based on admin settings.

== Description ==

**All Nofollow** is a powerful WordPress plugin designed to automatically add the `rel="nofollow"` attribute to external links and specified internal links within your content. This helps improve your site's SEO by controlling how search engines crawl and index your links.

**Key Features:**

- **External Links Settings:**
  - Automatically add `nofollow` to all external links.
  - Option to open all external links in a new browser tab.

- **Internal Links Settings:**
  - Add `nofollow` to links pointing to the author's archive page.

**Benefits:**

- Enhances SEO by managing link attributes efficiently.
- Saves time by automating the process of adding `nofollow`.
- Improves user experience by controlling link behaviors.

**Why Choose All Nofollow?**

Managing `nofollow` attributes manually can be tedious, especially for websites with numerous links. **All Nofollow** streamlines this process, ensuring consistency and adherence to SEO best practices without the need for manual intervention.

== Installation ==

1. **Upload the Plugin:**
   - Upload the `all-nofollow` folder to the `/wp-content/plugins/` directory on your WordPress server.

2. **Activate the Plugin:**
   - Log in to your WordPress admin dashboard.
   - Navigate to **Plugins > Installed Plugins**.
   - Locate **All Nofollow** in the list and click **Activate**.

3. **Configure Settings:**
   - After activation, go to **Settings > All Nofollow**.
   - Configure the settings according to your preferences:
     - **External Links:**
       - Enable `nofollow` for all external links.
       - Choose to open external links in a new tab if desired.
     - **Internal Links:**
       - Enable `nofollow` for links pointing to the author's archive page.
   - Click **Save Changes** to apply your settings.

== Frequently Asked Questions ==

= What is a rel nofollow link? =

A `rel="nofollow"` link is an HTML attribute that instructs search engines not to follow or pass SEO credit to the linked page. This attribute is often used to prevent spammy or untrusted links from affecting a website's search engine rankings. By adding `nofollow` to a link, you signal to search engines that you don't endorse the content of the linked page, helping to maintain the integrity and credibility of your site.

= How to add (set) nofollow to external links in WordPress? =

Adding `nofollow` to external links in WordPress can be achieved manually or by using plugins. Manually adding `nofollow` involves editing each link in your posts or pages and adding the `rel="nofollow"` attribute. However, this can be time-consuming, especially for sites with numerous links.

**Using the All Nofollow Plugin:**

1. **Install and Activate the Plugin:**
   - Upload the `all-nofollow` plugin to your WordPress site and activate it through the **Plugins** menu.

2. **Navigate to Settings:**
   - Go to **Settings > All Nofollow** in your WordPress admin dashboard.

3. **Configure External Links Settings:**
   - **Add `nofollow` to External Links:** Check this option to automatically add `rel="nofollow"` to all external links in your content.
   - **Open External Links in New Tab:** Optionally, enable this to have all external links open in a new browser tab.

4. **Save Changes:**
   - Click **Save Changes** to apply the settings.

Once configured, the **All Nofollow** plugin will automatically manage the `nofollow` attributes for external links, ensuring consistency and saving you valuable time.
