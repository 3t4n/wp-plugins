== Description ==

📢 **Join our new community [Bit Flows](https://www.facebook.com/groups/bitapps) & get updates of our new plugin.**

Bit Flows is a powerful, self-hosted automation tool for WordPress that enables you to create custom workflows and automate tasks without limitations. Whether you're automating within WordPress or integrating with external platforms like Shopify, Google Sheets, MailChimp, and more, Bit Flows makes it easy to streamline your processes.

With features like **Custom Apps** for connecting to any API, **Webhooks** for seamless integration, and a suite of automation tools (Router, Delay, Repeater, Iterator, Conditional Logic), Bit Flows gives you full control over your workflows. You can integrate with both WordPress plugins and third-party services using just a few clicks.

**Key Features:**
- **Unlimited Workflows:** Create custom workflows to automate tasks within WordPress and beyond.
- **Custom Apps:** Integrate any API or service with ease, even if it's not built into Bit Flows.
- **Webhook Support:** Use incoming and outgoing webhooks to connect any app or plugin that supports webhooks.
- **Flexible Integrations:** Connect to platforms like Shopify, MailChimp, Google Sheets, BigCommerce, and more.
- **No SaaS Limitations:** A self-hosted solution that gives you full control without the limitations of traditional SaaS tools like Zapier or n8n.

Bit Flows works seamlessly within your WordPress environment while providing the flexibility to integrate with virtually any service that supports an API or webhook. Perfect for small businesses, agencies, and developers looking for a cost-effective and scalable solution to automate their workflows.

[https://www.youtube.com/watch?v=HVKNTAY2TSQ]

**How It Works:**
1. Install Bit Flows on your WordPress site.
2. Create custom workflows by choosing triggers, actions, and conditions.
3. Automate processes both inside and outside of WordPress.
4. Integrate with any API or service using Custom Apps and Webhooks.

Bit Flows is ideal for automating everything from simple tasks to complex processes, all within a single platform. Save time, reduce errors, and boost productivity with the power of automation!

== Installation ==

1. Download the plugin.
2. From the WordPress Admin Panel, click on Plugins => Add New.
3. Click on Upload, so you can directly upload your plugin zip file.
4. Use the browse button to select the downloaded plugin zip file, and then click Install Now.
5. Once installed, click “Activate”.
