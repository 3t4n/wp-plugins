A simple and efficient WordPress plugin to manage URL redirections for your website. Add, edit, delete, and bulk upload redirections with ease.

== Description ==

Advanced Redirection Tool is a lightweight plugin designed to help you manage URL redirections easily. This plugin is perfect for improving SEO, handling broken links, and managing URL changes.

Features in Version 1.0:
- Add new URL redirections.
- Edit and delete existing redirections.
- Automatically redirect users to the target URLs.
- Simple and user-friendly interface.

Use Cases:
- Redirect outdated or broken URLs to new ones.
- Manage URL changes during website migration or redesign.
- Avoid 404 errors to maintain user experience and SEO ranking.

Why Choose Advanced Redirection Tool?
- Simplifies redirection management.
- Provides an intuitive dashboard for quick actions.
- Optimized for performance and ease of use.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/advanced-redirection-tool/` directory, or install the plugin directly through the WordPress Plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to Tools > Advanced Redirection Tool to start adding and managing redirections.

== Frequently Asked Questions ==

= How do I add a new redirection? =
1. Go to Tools > Advanced Redirection Tool.
2. Enter the "From URL" and "To URL" in the form.
3. Click Add Redirection.

= Can I edit or delete redirections? =
Yes, the plugin provides options to edit or delete existing redirections.

= Can I upload redirections in bulk? =
Yes, you can upload a CSV file containing multiple redirections using the Upload CSV option.

= Does this plugin work with relative URLs? =
Yes, the plugin supports both relative and full URLs.

= Does it support regex or wildcard redirects? =
Currently, this version supports exact URL matching only.
