== Description ==
The most powerful and advance visual styling plugin. This plugin gives you to customize any page or post design without codding. Click on an element or add a custom selector to start customizing. Change an element color, line height, letter spacing, and more. instantly with live preview. [Try It Now](http://demo.cantothemes.com/wp/glamour-pro/?glamour=edit&glmrmode=single)

Now, you will be able to change the design of your site without changing the theme. Glamour provides full control over the design of your site.

=== Key Features ===
* Design every element on Page/Post
* Design header, footer, widgets or any content
* Auto and manual both selector available
* 70+ CSS Properties (more coming)
* Visual drag and drop position (Pro)
* Visual resizeable  padding (Pro) and margin
* 850+ Google fonts (Pro)
* Gradient Background (Pro)
* Live Preview
* Responsive design for the small laptop, tablet and mobile phone
* Style element state hover, active and focus
* Custom color presets (Pro)

=== Free vs Pro === 
The free version has some limited features like the background, gradient background, google fonts, box shadow, transform, etc. To unlock these features you can [purchase pro version](https://www.cantothemes.com/item/glamour-pro-visual-styling-wordpress-plugin/).

== Installation ==

1. Upload the entire `glamour` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

== Frequently Asked Questions ==

= Can I change the content of my website? =
No, It's just a visual CSS editor. to edit content try Page Builder Plugin.
