== Description ==

The plugin gives you the opportunity to use and publish illustrations with affiliate links from Depositphotos, one of the leading photobanks in the world. After adding the keywords, Depositphotos will suggest relevant and themed images. You will be able to get relevant visual content and profit from your readers. For using the plugin, you will need a Depositphotos affiliate account.

== Installation ==

There is several ways to install this plugin:

1. Install via WordPress Plugins manager panel (Plugins -> Add New -> Search -> Install Now ).
2. Download zip archive from wordpress.org and install via WordPress Plugins manager (Plugins -> Add New -> Upload Plugin -> Install Now).
3. Download zip archive from wordpress.org, unpack it and upload `depositphotos_affiliate` folder to `wp-content/plugins/` on your site via FTP.

== Frequently Asked Questions ==

To use the plugin, you need to get a tracking code from the Depositphotos affiliate program.
Register by clicking on this link: https://depositphotos.com/affiliate/signup.html
After registration, you will receive a confirmation with a unique code that looks like this: tracking.depositphotos.com/aff + unique identifiers\
In Wordpress, go to plugin settings and note the identifier in the field 'Your tracking link'
Before publishing, press the shortcode button to add the block to your publication.
Install your plugin correctly with the use of keywords or categories so that your photographs will be thematically fitting to your publication.
