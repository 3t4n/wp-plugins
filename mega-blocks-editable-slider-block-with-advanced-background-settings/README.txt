== Description ==

Mega Blocks - Editable Slider Block provides a powerful, customizable slider for the WordPress block editor (Gutenberg). It comes with Bootstrap 4, Swiper.js, background settings, and various customization options for your needs.

== Installation ==

* Upload the plugin files to the /wp-content/plugins/mega-blocks-editable-slider-block-with-advanced-background-settings directory, or install the plugin through the WordPress plugins screen directly.
* Activate the plugin through the 'Plugins' screen in WordPress.
* Edit or create a new page and add the "Mega Slider Block" from the Gutenberg block library.

Customize your slider's appearance with the background and animation settings.

= What is Mega Gutenberg Slider, and how does it work? =

Mega Gutenberg Slider is a flexible and powerful WordPress slider plugin designed to help you create visually stunning sliders with ease. It offers a no-code, visual editor with drag-and-drop functionality, making it accessible for beginners and advanced users alike.

= Is Mega Gutenberg Slider compatible with popular page builders? =

Yes! Mega Gutenberg Slider is fully compatible with popular page builders such as Elementor, WPBakery, and Divi. This allows you to seamlessly integrate sliders into any layout created with these page builders.

= Can I customize the slider’s appearance without coding? =

Absolutely! The plugin includes a visual editor where you can adjust fonts, colors, animations, and more with just a few clicks. No coding skills are required to create fully customized sliders.

= Is Mega Gutenberg Block Slider compeletely free with premium features? =

Yes, Mega Gutenberg Slider has a compeletely free with all premium features.

= What types of animations are available for text and content? =

Mega Gutenberg Slider offers a wide range of animations for headings, subheadings, and content, including effects like "Bounce," "Fade In," "Zoom In," and more. You can choose animation types and set individual delays to create dynamic content that captures attention.

= Can I use custom fonts in my sliders? =

Yes! The slider block supports a variety of Google Fonts that you can apply to headings, subheadings, and content. Choose from fonts like Roboto, Lato, and Oswald, and customize the size, color, and weight to fit your branding.

= Does Mega Gutenberg Slider support video backgrounds? =

Absolutely! You can set custom video backgrounds using URLs or embed videos from YouTube and Vimeo. Each video can be set to autoplay, loop, and mute, allowing for highly engaging background visuals.

= How can I control the overlay and opacity for background images? =

You can add a color overlay to background images to improve text readability or achieve a specific visual effect. Adjust the overlay color and opacity using the plugin settings for a customized look.

= Can I add social media icons to my sliders? =

Yes, Mega Gutenberg Slider supports adding social media icons in different positions. You can customize icon colors, sizes, and hover effects to ensure they align with your design.

= What customization options are available for buttons in sliders? =

The slider buttons are fully customizable, including options for background color, font color, border radius, and border color. You can also set hover colors for both the button and font, ensuring an interactive experience.

= Is there support for two-column layouts? =

Yes! You can set up two-column layouts for slides, with options for left and right image or video placements. Control image dimensions, border radius, and switch layout directions as needed.

= Can I adjust padding, margins, and border radius for the sliders? =

Mega Gutenberg Slider allows you to set custom padding, margins, and border radius for each slide, enabling you to refine the spacing and layout for each slide element.
