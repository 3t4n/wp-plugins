ChatGPTを利用してSEOに最適化された記事を自動生成するWordPressプラグインです。

== 説明 ==

AI Article Generatorは、OpenAIのChatGPT APIを使用して、SEOに最適化された記事を自動生成するWordPressプラグインです。このプラグインを使用することで、高品質なコンテンツを効率的に作成し、ウェブサイトのSEOパフォーマンスを向上させることができます。

主な機能：
* ChatGPT APIを使用した記事の自動生成
* テーマ、プロンプト、トーンの設定が可能
* 生成された記事の重複チェック機能
* 下書き保存または自動公開のオプション

== インストール ==

1. プラグインファイルを `/wp-content/plugins/` ディレクトリにアップロードするか、WordPressの管理画面からプラグインを直接インストールします。
2. WordPressの管理画面で、プラグインを有効化します。
3. 設定 > AI記事生成 メニューから、OpenAI APIキーを入力し、その他の設定を行います。

== 外部サービス ==


このプラグインは記事コンテンツを生成するためにOpenAI APIを使用します。

記事が生成されるたびに、ユーザが指定したテーマ、プロンプト、トーンをOpenAI APIに送信します。
APIキーと生成されたコンテンツは安全に送信されます。

本サービスはOpenAIが提供します： 
- 利用規約: https://openai.com/policies/terms-of-use
- プライバシーポリシー: https://openai.com/policies/privacy-policy

== よくある質問 ==

= このプラグインを使用するにはOpenAI APIキーが必要ですか？ =

はい、このプラグインを使用するにはOpenAI APIキーが必要です。OpenAIのウェブサイトでアカウントを作成し、APIキーを取得してください。

= 生成された記事は自動的に公開されますか？ =

設定画面で選択したオプションに応じて、生成された記事を下書きとして保存するか、自動的に公開するかを選択できます。

= 生成された記事の品質はどの程度ですか？ =

ChatGPT APIを使用して生成される記事は一般的に高品質ですが、必ず人間による確認と編集を行うことをお勧めします。
