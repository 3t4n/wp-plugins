Enhance Gravity Forms with date filters, unique IDs, date picker animations and more.

== Description ==

Hero is an add-on to [Gravity Forms](https://www.gravityforms.com) which provides essential features and adds extra functionality.

= Features =

* **[Date Filters](https://toroguapo.com/gf-hero/documentation/date-filters)**. You can use date filters to enable or disable calendar dates such as past dates, weekends, holidays, or any other specific dates.
* **[Time Zones](https://toroguapo.com/gf-hero/documentation/date-time-zones)**. When using a date picker, you need to be aware of time zones if you expect global visitors. Hero adds time zone support to date fields.
* **[Date Picker Animations](https://toroguapo.com/gf-hero/documentation/date-animations)**. Hero gives you control over which animation to play when opening a date picker.
* **[Date Picker Highlights](https://toroguapo.com/gf-hero/documentation/date-highlights)**. You can use Hero to highlight today's date on the calendar.
* **[Read Only Date Inputs](https://toroguapo.com/gf-hero/documentation/date-properties)**. With Hero, you can disallow manual edits of date inputs and only allow date inputs to be filled by a date picker.
* **[Unique IDs](https://toroguapo.com/gf-hero/documentation/generator-unique-ids)**. When you need to create coupon codes, reference numbers, or anything that needs to be random as well as unique, you can use unique IDs.
* **[Random IDs](https://toroguapo.com/gf-hero/documentation/generator-random-ids)**. When you just need to generate random characters, you can use random IDs.

== Installation ==

Since [Hero](https://toroguapo.com/gf-hero/) is an add-on to Gravity Forms, you need to have [Gravity Forms](https://www.gravityforms.com) installed and active in order to use Hero.

Hero comes in three variants:

1. [Hero Essential](https://toroguapo.com/gf-hero/#pricing-1), the plugin variant that includes essential functionality and can be downloaded for free.

2. [Hero Standard](https://toroguapo.com/gf-hero/#pricing-2), which includes extra features not part of the Essential variant. You can download this variant after obtaining a license from https://toroguapo.com/gf-hero/

3. [Hero Advanced](https://toroguapo.com/gf-hero/#pricing-3), which adds more advanced functionality on top of what the Standard variant offers. See https://toroguapo.com/gf-hero/ for more details on this variant as well.
