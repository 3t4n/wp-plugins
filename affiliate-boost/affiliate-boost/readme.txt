O Affiliate Boost aumenta as chances de conversão em seu afiliado, abrindo abas contextualizadas, aumentando suas receitas com o mínimo de esforço.

== Descrição ==

O **Affiliate Boost ** é um plugin desenvolvido para blogs de viagens, turismo e outros nichos que utilizam links de afiliados. Ele permite que você adicione links de afiliados diretamente nas categorias do WordPress, oferecendo uma experiência automatizada e não invasiva para seus visitantes. Com configurações flexíveis, você pode controlar quando e como os links serão abertos, maximizando as chances de conversão.

== Funcionalidades ==

- **Adicionar links de afiliados às categorias:** Insira links de afiliados diretamente nas categorias do WordPress.
- **Redirecionamento automático:** Os links são abertos automaticamente em uma nova aba, com base no evento escolhido (carregamento da página, primeiro clique, tentativa de saída ou primeiro scroll).
- **Configurações personalizáveis:**
  - **Tempo de espera:** Defina o tempo (em segundos) antes que o link seja aberto.
  - **Duração da sessão:** Controle por quantos dias o redirecionamento não será repetido para o mesmo visitante.
  - **Evento de disparo:** Escolha o evento que acionará o redirecionamento (carregar a página, primeiro clique, tentativa de saída ou primeiro scroll).
  - **Status do plugin:** Ative ou desative o plugin facilmente.
- **Experiência não invasiva:** O plugin só abre o link de afiliado se ele estiver configurado e ativo para a categoria visitada.
- **Escalável:** Pronto para expansão com novos recursos, como A/B testing e múltiplos links de afiliados.

== Instalação ==

1. Faça o upload do plugin para a pasta `/wp-content/plugins/` ou instale diretamente pelo painel de administração do WordPress.
2. Ative o plugin no menu "Plugins".
3. Acesse o menu "Configurações -> Affiliate Boost" no painel de administração para configurar as opções:
   - Defina o tempo de espera, a duração da sessão e o evento de disparo.
   - Adicione links de afiliados nas categorias desejadas.
4. Pronto! O plugin começará a funcionar automaticamente.

== Perguntas Frequentes ==

= O plugin é compatível com outros temas? =
Sim, o Affiliate Boost é compatível com a maioria dos temas do WordPress.

= Posso usar o plugin para outras plataformas além de viagens? =
Sim, o plugin pode ser usado para qualquer nicho que utilize links de afiliados, como e-commerce, cursos online, etc.

= O que acontece se não houver um link de afiliado configurado para uma categoria? =
O plugin não fará nada. Ele só abre o link de afiliado se ele estiver configurado e ativo para a categoria visitada.

= Como o plugin lida com a privacidade do usuário? =
O plugin não coleta dados dos usuários. Ele apenas abre o link de afiliado em uma nova aba, respeitando as configurações de tempo e evento.

== Exemplo de Uso ==

1. Crie uma categoria chamada "Buenos Aires".
2. Obtenha um link de afiliado do Booking.com para hotéis em Buenos Aires.
3. Adicione o link de afiliado no campo personalizado da categoria "Buenos Aires".
4. Configure o plugin:
   - Tempo de espera: 10 segundos.
   - Duração da sessão: 1 dia.
   - Evento de disparo: Primeiro clique.
5. Quando um visitante navegar por um post da categoria "Buenos Aires", após 10 segundos do primeiro clique, o link de afiliado será aberto automaticamente em uma nova aba.
