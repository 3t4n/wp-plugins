An easy way to implement the FFSystems widget to your Wordpress sites.

== Description ==

With this plugin you can add your [FFSystems](https://ffsystems.nl/?ref=wordpress-plugin) widget to your WordPress site.

This plugin adds the [FFSystems](https://ffsystems.nl/?ref=wordpress-plugin) service to your website. It uses an external service to process takeaway/delivery orders and/or restaurant reservations. This is done by including a JavaScript-snippet to your website via our Content Delivery Network (via the domain *.ffsystems.nl) or your custom domain. You will need an active account on [FFSystems](https://ffsystems.nl/?ref=wordpress-plugin-active-account) to use this plugin.

FFSystems has different products that could be used with this plugin. The available services (if they are activated for your team) are:
- [FFAfhalen for takeaway/delivery](https://ffafhalen.nl/?ref=wordpress-plugin)
- [FFReserveren for restaurant reservations](https://ffreserveren.nl/?ref=wordpress-plugin)

For more information about which data FFSystems is processing, you can take a look at this [Terms of Service](https://legal.ffsystems.nl/terms?ref=wordpress-plugin) & [Privacy Policy](https://legal.ffsystems.nl/privacy?ref=wordpress-plugin).

== Installation ==

1.
    A: In your WordPress admin panel, go to *Plugins > New Plugin*, search for **FFSystems** and click "*Install now*"
    B: Alternatively, download the plugin and upload the contents of `ffsystems.zip` to your plugins directory, which usually is `/wp-content/plugins/`.
3. Activate the plugin
