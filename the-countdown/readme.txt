A plugin for displaying counter for your site and do action after or before it hit the expiration.

== Description ==

The countdown functionality can easily be added to your block or sidebar. With counting down and up functionality, gives you a full control to your counter. 
This plugin comes with bunch of timer option such as the ability to count up/down or even do relative time.
There are many tempates available with lot of styles for each template that can be customized easily.

<h3><strong>Key Features & Options</strong></h3>
<ul>
<li>Date Picker for your until, since or relative counter.</li>
<li>Date Format easy to use custom date format for display.</li>
<li>Expiry option to show message, redirect to an URL or even run JavaScript function.</li>
<li>Custom labels the display texts for the counters, singular, plural name.</li>
<li>Builtin template with lots of style options.</li>
</ul>

== Installation ==

You can use the built in installer and upgrader, or you can install the plugin manually.
1. Go to the menu 'Plugins' -> 'Install' and search for 'The Countdown'
2. Click 'install'.
