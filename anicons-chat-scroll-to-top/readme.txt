Adds Animated Floating Button for the footer, WhatsApp Icon Button & Scroll-to-Top Icon Button.


=== Description ===
Anicons, a lightweight WordPress plugin that adds floating WhatsApp Chat and Scroll-to-Top buttons to the footer. This plugin allows visitors to easily start a WhatsApp chat with just one click and smoothly navigate back to the top of the page.

https://www.youtube.com/watch?v=kC2qM2_g8lk

=== WhatsApp Chat Button Features ===

✅ On desktop, it opens WhatsApp Web, while on mobile, it launches the WhatsApp app.
✅ Position the button on the left or right side of the screen.
✅ Add your WhatsApp or WhatsApp Business number.

=== Scroll to Top Button Features ===

✅ Displays a sticky Back/Scroll-to-Top button.
✅ Automatically appears when users scroll down.
✅ Choose from multiple icon styles.
✅ Adjustable position settings.

=== Performance & Optimization ===

- Lightweight and fast-loading for optimal website speed.
- No impact on Google PageSpeed performance.

=== Installation Guide ===

1. Go to Plugins → Add New.
2. Search for Anicons – Chat & Scroll to Top Icons.
3. Click Install Now, then Activate.

== Manual Installation ==

1. Download the plugin ZIP file.
2. Extract the contents to `/wp-content/plugins/anicons-chat-scroll-to-top/`.
3. Activate the plugin via Plugins in the WordPress dashboard.

=== How to Use ===

- Once activated, the plugin automatically displays:
  - WhatsApp Chat Button.
  - Scroll-to-Top Button.
- Adjust settings if customization is needed.
  - Ensure you add a mobile number for the WhatsApp icon to appear.
  - A default position of 20px is set; adjust if needed.

=== Frequently Asked Questions ===

= How do I set up the plugin? =

[Video Tutorial](https://www.youtube.com/watch?v=kC2qM2_g8lk)

= How do I add my WhatsApp number? =

Go to Anicons Settings in WordPress and enter your WhatsApp number.

= What should I do if the buttons are not visible? =

1. Ensure the plugin is activated.
2. Clear your website and browser cache.
3. Verify the button position settings.
