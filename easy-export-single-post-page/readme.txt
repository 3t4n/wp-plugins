== Description ==

Easy Export Single Post and Page WordPress plugin allows users to easily export individual posts or pages in various formats for seamless sharing and backup.



== Installation ==
1. Upload [`easy-export-single-post-page`] to the `/wp-content/plugins/` directory

2. Activate the plugin through the 'Plugins' menu in WordPress

3. Visit manage post/page admin; hover any post/page and you will see the Export section..
