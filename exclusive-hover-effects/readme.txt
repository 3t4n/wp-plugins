== Installation ==

Installing this plugin as regular wordpress plugin.

After install, this plugin enable a custom post called <strong>"exeffects"</strong>. Add category & items on that custom post. 
After adding items, you are ready to use this plugin in your post, page, widget or anywhere you like. 

Go to page > Add New. On the editor, you will see a blue button  by clicking button you see the shortcode like <code>[ex_effects category="Category_Name" style="style1"]</code>

Use category title, not category id or slag. Make sure spelling is ok. It is case sensitive.
