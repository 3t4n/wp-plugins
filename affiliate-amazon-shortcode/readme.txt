== Description ==

Affiliate Amazon Shortcode is a lightweight yet powerful WordPress plugin that allows you to display Amazon products directly in your posts, pages, or widgets using the Amazon Product Advertising API v5. With this plugin, you can easily integrate Amazon affiliate links, generate rich snippets, and enhance your affiliate marketing strategy without writing any code.
Ideal for bloggers, affiliate marketers, and e-commerce websites, with Affiliate Amazon Shortcode, you can effectively monetize your website and increase your earnings through the Amazon Affiliate Program. 
Try the plugin now and start earning with Amazon.

**Features:**
- Display up to 9 products based on a keyword, with customizable layouts.
- Intuitive settings page for configuring Amazon API credentials and plugin options.
- Supports multiple marketplaces (e.g., amazon.it, amazon.com).
- Automatically fetches product images, descriptions, prices, and reviews
- Flexible customization: number of columns, image size (medium or large), and font sizes for titles and prices.

**Usage:**
Once the plugin is configured, use the `[affiamsh_amazon keyword="your-keyword"]` shortcode in your posts or pages to display Amazon products related to your keyword.

== Installation ==

1. Download the plugin and upload it to your WordPress site.
2. Navigate to `Plugins > Add New > Upload Plugin` and upload the `.zip` file.
3. Activate the plugin through the `Plugins` menu in WordPress.
4. Configure your Amazon API credentials in `Settings > Amazon API`.
5. Use the shortcode `[affiamsh_amazon keyword="your keyword"]` to display products.

== Frequently Asked Questions ==

= How do I get Amazon API credentials? =
Create an Amazon Associates account and generate API keys through the Amazon Product Advertising API dashboard. For detailed instructions, check the [official documentation](https://webservices.amazon.com/paapi5/documentation/).

= Why are no products displaying? =
Ensure your API credentials, partner tag, and marketplace settings are correct. Double-check that your keyword matches available products in the selected Amazon marketplace.

= Can I customize the product display layout? =
Yes, you can configure the number of columns, image sizes, and font sizes for titles and prices in the plugin settings page.
