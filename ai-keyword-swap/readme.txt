AI Keyword Swap is a WordPress plugin that identifies and replaces SEO-blocked words in your content using OpenAI.

== Description ==

AI Keyword Swap is a powerful WordPress plugin designed to effortlessly enhance your website's SEO compliance. This innovative tool allows you to create and manage a list of SEO-blocked keywords, ensuring your content remains optimized and search engine-friendly. Using advanced AI technology from OpenAI, the plugin scans your pages and posts, identifying any blocked keywords that might harm your search engine rankings. It then intelligently suggests and replaces these words with more appropriate alternatives, maintaining the integrity and readability of your content. With AI Keyword Swap, you can safeguard your site from SEO penalties, improve your visibility, and keep your content in line with search engine guidelines seamlessly.

**OpenAI API key**

First, create an [OpenAI account](https://platform.openai.com/signup "Click to create the OpenAI account") or [sign in](https://platform.openai.com/login "Click to login OpenAI account"). Next, navigate to the [API key page](https://platform.openai.com/account/api-keys "Click to open API key page") and "Create new secret key", optionally naming the key. Make sure to save this somewhere safe and do not share it with anyone.

For optimal results, consider using a Pro OpenAI key, which may offer enhanced features and performance.

If you encounter any issues during this process, refer to OpenAI's documentation or support resources for further assistance.

FYI, This plugin is compatible with the classic editor. Also, Please ensure you have an OpneAI API credit limit for using the OpenAI API key.

== Installation ==

= Installation from within WordPress =

1. Visit **Plugins > Add New**.
2. Search for **AI Keyword Swap**.
3. Install and activate the Plugin Check plugin.

= Manual installation =

1. Upload the entire `ai-keyword-swap` folder to the `/wp-content/plugins/` directory.
2. Visit **Plugins**.
3. Activate the Plugin Check plugin.

== Frequently Asked Questions ==

= Where can I configure the plugin settings? =

Go to the wordpress dashboard, check for the "AI Keyword Swap" in the left menu, and click on it, here you see the options for the Keywords, OpenAI API Key, and OpenAI API Endpoint.

= Where can I configure the unwanted words? =

In the "AI Keyword Swap" settings page, there is an option labeled 'Keywords' to manage the keyword list. You simply need to add one keyword per line.

= How can I replace the words in a page or post content =

You need to go to the particular page or post and edit the page, here you can see the option on the editor to "Scan Article" and "Replace Highlighted Words".

First, you need to scan the page or post content and then it will highlight the words according to the keywords added in the plugin settings page.

Those highlighted words you can replace by directly clicking on the highlighted word or you can use the "Replace Highlighted Words" button to replace the words.

= How to create an OpenAI API key? =

First, create an [OpenAI account](https://platform.openai.com/signup "Click to create the OpenAI account") or [sign in](https://platform.openai.com/login "Click to login OpenAI account"). Next, navigate to the [API key page](https://platform.openai.com/account/api-keys "Click to open API key page") and "Create new secret key", optionally naming the key. Make sure to save this somewhere safe and do not share it with anyone.
