== Installation ==

**First installation**

1. Upload the plugin files to the `/wp-content/plugins/estoreinfo-manager` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Once activated you can manage everything by going to the `eStoreInfo` menu.

**Subsequent upgrades**

1. Just upgrade using the plug-in panel
