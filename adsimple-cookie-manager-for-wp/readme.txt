Cookie Banner WordPress plugin to add a GDPR-compliant cookie banner, ensuring user consent for all non-essential cookies on your website.

== Description ==

With this Cookie Banner WordPress plugin, you can install a cookie banner on your WordPress website in just a few steps.
The cookie banner ensures the legally required consent for all cookies that are not "technically necessary".

- Register and log in at [AdSimple](https://www.adsimple.at/anmelden/) if you don’t have an account with us yet.
- Install and activate this WordPress plugin on your WordPress website.
- Copy the AdSimple ID from the Consent Manager, which you can find at [AdSimple ACM](https://www.adsimple.at/consent-manager/), into the input field.
- Click SAVE.
- Configure all additional settings in the [Consent Manager](https://www.adsimple.at/dashboard/mein-consent-manager/).
- If you want to display an ordered list of all cookies on a subpage, you can easily do so by adding the shortcode [acm_cookie_list].


== Features ==

The AdSimple Consent Manager offers a comprehensive solution for GDPR-compliant management of cookies and external resources on your website. The key features include:

🔒 Automatic Cookie and Resource Blocking: Third-party cookies and external resources are automatically blocked until the user gives consent.

🎭 Customizable Cookie Banner: The cookie banner can be customized in terms of text, color, and layout to seamlessly match your website's design.

🧐 Detailed Cookie Management: Cookies are categorized for easy management by users. The banner also allows users to give consent by category.

⏳ Regular Scanning: The Consent Manager scans your website monthly to detect new cookies and external resources.

🌍 Multilingual Support: The Consent Manager supports multiple languages, making it ideal for international websites.

🔨 Script Blocking: Scripts are blocked until the user gives consent, which is crucial for GDPR compliance.

With these features, the AdSimple Consent Manager ensures easy and effective management of user consents, keeping your website GDPR-compliant.

For more information about the AdSimple Consent Manager, visit: [AdSimple ACM](https://www.adsimple.at/consent-manager/)


== Installation ==

= Automatic installation =
- Click on **Plugins** from your WordPress dashboard and select **Add New Plugin**.

- Search for 'AdSimple', click on "Cookie-Banner-Plugin für WordPress – Consent Manager von AdSimple (DSGVO/GDPR)" and **Install Now**.

- Click **Activate** to enable the plugin and you will be redirected to the Consent Manager Dashboard in green where you can enter the AdSimple ID.

= Manual installation by upload =
- Download the "Cookie-Banner-Plugin für WordPress – Consent Manager von AdSimple (DSGVO/GDPR)" plugin zip file from the WordPress.org page.

- Go to **Plugins** from your WordPress dashboard and select **Add New Plugin**.

- Click **Upload Plugin** and choose the downloaded zip file.

- Click **Install Now** and after installation, click **Activate Plugin**.

= Manual installation by FTP =
- Use an FTP application to upload the ZIP file.

- Extract the ZIP file and place the folder in your /wp-content/plugins/ directory.

- Go to your WordPress dashboard and activate the plugin.

After the installation you are presented with the dashboard of the plugin where you can enter the AdSimple ID. 
Those are the steps to obtain it:

- Register and log in at [AdSimple](https://www.adsimple.at/anmelden/) if you don’t have an account with us yet.
- Copy the AdSimple ID from the Consent Manager, which you can find at [Consent Manager](https://www.adsimple.at/dashboard/mein-consent-manager/), into the input field.
- Click SAVE.
- Configure all additional settings in the Consent Manager at [Consent Manager](https://www.adsimple.at/dashboard/mein-consent-manager/).
- If you want to display an ordered list of all cookies on a subpage, you can easily do so by adding the shortcode [acm_cookie_list].

== Frequently Asked Questions ==

= Is the AdSimple Consent Manager free? =
Yes. The AdSimple Consent Manager is available in a free version.

= Is registration on adsimple.at required? =
Yes. Through your user account, you can centrally manage one or multiple cookie notice scripts with the AdSimple Consent Manager.

= What is the AdSimple ID? =
In your dashboard on adsimple.at, under the "Consent Manager" menu, you'll find the necessary AdSimple ID to connect to your website and integrate the script code.

= How can I customize the cookie banner? =
You can customize the text, color, and layout of the cookie banner through the Consent Manager settings on adsimple.at.

= How often does the Consent Manager scan my website? =
The Consent Manager performs monthly scans of your website to detect any new cookies or external resources.

= Can I display a list of cookies on my website? =
Yes, you can display an ordered list of all cookies on a subpage by using the shortcode [acm_cookie_list].

= Does the Consent Manager support multiple languages? =
Yes, the Consent Manager supports multiple languages, making it suitable for international websites.

= What happens if a user does not give consent? =
If a user does not give consent, third-party cookies and external resources will remain blocked to comply with GDPR regulations.

= How do I block scripts until consent is given? =
The Consent Manager automatically blocks scripts until the user provides consent, ensuring GDPR compliance.

= Can I manage multiple websites with one AdSimple account? =
Yes, you can manage multiple websites and cookie notice scripts from a single AdSimple account.

= Is the Consent Manager compatible with all WordPress themes? =
Yes, the AdSimple Consent Manager is designed to be compatible with all WordPress themes.

= How do I update the Consent Manager plugin? =
You can update the plugin through your WordPress dashboard, just like any other plugin. We recommend backing up your website before updating.

= Does the Consent Manager work with caching plugins? =
Yes, the Consent Manager is compatible with most caching plugins, including WP Rocket. Specific logic is implemented to ensure compatibility.
