== Installation ==
<strong>MINIMUM REQUIREMENTS</strong>
1.Upload the plugin folder to your /wp-content/plugins/folder.
2.Go to the Plugins page and activate the plugin.
3.Visit the <a href="https://exlyapp.com/knowledgebase/">Exlyapp.com/knowledgebase</a> for a detailed list of server requirements.


<strong>AUTOMATIC INSTALLATION</strong>
Automatic installation is the easiest option — WordPress will handle the file transfer, and you won’t need to leave your web browser. To automatically install Exly WP, log in to your WordPress dashboard, navigate the Plugins menu, and click <strong>Add New.</strong> 
In the search field, type <strong>Exly WP</strong>, then click <strong>Search Plugins</strong>. Once you’ve found us, you can check out details like the point release, rating, and description. Most importantly, you can install it by clicking <strong>Install Now</strong>, and WordPress will take it from there.


<strong>MANUAL INSTALLATION</strong>
The manual installation method requires downloading the ExlyWP plugin and uploading it to your web server via your favorite FTP application. The WordPress codex contains <a href="https://wordpress.org/support/article/managing-plugins/#manual-plugin-installation">instructions on how to do this here.</a>



<strong>UPDATING</strong>
Automatic updates should work smoothly, but we recommend you always back up your site.
If you encounter issues with the Shop/Category pages after an update, flush the permalinks by going to WordPress > Settings > Permalinks and hitting the <strong>Save</strong> button. That should restore the settings.
