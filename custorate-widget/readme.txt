== Description ==

Als u klantenbeoordelingen op uw website wilt. dan is dit de beste manier om dat voor elkaar te krijgen, installeer de widget en meldt u aan!

Daarna krijgt u een API Key van ons die u eenvoudig kan toevoegen en u bent klaar om te gaan! Makkelijker dan dit gaat het niet worden.

== Installation ==

Unzip dit bestand en zet het in de plugin folder. Of gebruik wordpress zelf om te uploaden.
