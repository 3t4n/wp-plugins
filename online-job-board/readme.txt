A comprehensive tool for creating and managing job listings on your website.

== Description ==
Online Job Board plugin allows businesses to post job openings on their website. It supports custom post types for job management, shortcode display for easy embedding, and industry-specific categories. Easily manage and showcase job listings with a responsive design.

== Features ==
* Create, manage, and display job listings.
* Shortcode to show job posts on any page or post.
* Fully customizable job details, including company name, city, openings, address, button text & URL, and additional company information.
* Supports custom post types and categories.
* Responsive layout for all devices.
* Filter and search functionality to help users find relevant jobs easily.
* Option to upload company logos for each job listing.
* Set application deadlines and closing dates for each position.
* Job application forms for candidates to apply directly through the listing.
* Email notifications for new applications and job expiry reminders.
* SEO-friendly URLs for job listings to improve search engine visibility.
* Multilingual support for creating job listings in multiple languages.
* User role permissions to control access to job creation and management.
* Supports pagination for job listings on large sites.
* Customizable styling options to match your site’s branding.
* Integration with third-party tools for job tracking and analytics.
* Dashboard overview of job performance and applications.

== Installation ==

Install online job board plugin via the WordPress.org plugin directory or by uploading the files to your server.

After activating online job board , go to plugin menu.

Click on online job board and add new job fill all settings & publish page.

Go to how to use sabmenu and copy shortcode and embed shortcode on any Page/Post/Text Widget.

That's it. You're ready to go!
