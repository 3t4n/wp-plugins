Easily enhance your WordPress menu items with a variety of icons using AR Menu Icons.

== Description ==
AR Menu Icons is a simple yet powerful plugin that allows you to add icons to your WordPress menu items effortlessly. Whether you want to use icons from popular libraries like Dashicons, FontAwesome, Elusive, or Fontello, or upload custom SVG or image icons, this plugin provides flexibility and customization to make your menus more intuitive and visually appealing.


= Features =
1. Easily customize icon color, size, and position.
2. Manage icon spacing for perfect alignment.
3. Supports Dashicons FontAwesome and Themify Icons in the free version.
4. Add icons to menu items in just a few clicks.

Pro Version Features:

1. All features from the free version.
2. Full support for Elusive, Foundation, Elegant, Fontello, and Genericons icon libraries.
3. Ability to upload custom icons (SVG or Any Image).
4. Advanced styling and customization options for icons.


== Installation ==
1. Go to Plugins > Add New in WordPress.
2. Search for "AR Menu Icons".
3. Click "Install Now" and activate the plugin.
4. Navigate to Appearance > Menus to start adding icons to your menu items.

== Usage ==
1. After activation, go to Appearance > Menus.
2. Select a menu item and click "Add Icon".
3. Choose an icon from the available libraries or upload a custom one.
4. Save your menu to apply the changes.


== Frequently Asked Questions ==
= How do I add an icon to a menu item? =
Navigate to Appearance > Menus, select a menu item, and use the "Add Icon" option to choose an icon from Dashicons or other supported libraries. Save your changes to apply the icon.


= Can I upload custom icons? =
Yes, the Pro version allows you to upload your own SVG or image icons to customize your menu items even further.

= Is the plugin compatible with all WordPress themes? =
Yes, AR Menu Icons works with most WordPress themes. If your theme uses a custom walker for menus, you may need to check compatibility with the theme developer.


= Why are my icons not showing? =
Ensure your theme uses the default WordPress walker for menus. If you're using a custom walker, check if it supports menu item filters or contact your theme developer for assistance.

= Can I use multiple icon libraries? =
Yes! AR Menu Icons supports multiple icon libraries in both the free and pro versions. You can mix and match icons from Dashicons, FontAwesome, Elusive, and more in a single menu.
