== Installation ==

**How to Add Instagram Testimonials to WordPress - Automatic Installation (Recommended)**

1. Go to `Plugins > Add New`
2. Search for "Elfsight Instagram Testimonials" and install the plugin
3. Activate your Instagram Testimonials

**Manual Installation**

1. Download `elfsight-instagram-testimonials.1.3.1.zip` from `wordpress.org` and unzip it
2. Upload the `elfsight-instagram-testimonials` folder to `/wp-content/plugins/`
3. Go to `Plugins > Installed Plugins` and activate the newest Instagram Testimonials

= Manage Elfsight Instagram Testimonials =

After installation there are only few steps left before starting to use the plugin and to embed Instagram Testimonials to your website.

1. Click 'Instagram Testimonials' in WordPress menu to go to Instagram Testimonials page.
2. Use the editor to create and setup your first widget.
3. Copy-paste the widget's installation code into any place of your website.
