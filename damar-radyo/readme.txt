== Description ==



Bu Eklenti Sayesinde Wordpress Blogunuzda DamarRadyo Flash Player Kurulmaktadir.

- [Demo](http://www.damarradyo.net/) İçin Tıklayınız 




== Installation ==



1. Wordpress Admin panelinde, EKLENTİLER > Yeni EKLE ve  'Damar Radyo Player' olarak arama yapın.

2. 'Yükle' Tıklayın.

3. Wordpress Admin içinde , Görünüm > Bileşenler, içinde  'DamarRadyo.Net Player' istediğiniz bölüme sürükleyip, yerleştirin ve kaydedin..
