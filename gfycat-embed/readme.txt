Enables live embeding of Gfycat links

== Description ==

Enables live embedding of gfycat links in the editor. Also adds options for looping, autoplaying and max video width under the Media page of settings. The play button is just an html link, so it will adhere to the existing theme's style sheet.

== Frequently Asked Questions ==

= What's Gfycat? =

It's a service that converts gifs into mp4s and plays them back using the video tag. Check it out www.gfycat.com
