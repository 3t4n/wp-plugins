Changes your list-style navigation to a mobile-friendly, responsive dropdown navigation which is small if not in use and fixed to top.

== Description ==
The Bitkatapult Mobile-friendly Responsive Navigation Menu changes your standard list-style navigation to a mobile-friendly one.
You can set many things to make the navigation fitting your site-design and to modify the function of this plugin. If you wish, set it to position the menu fixed at the top of the screen, or attach the menu to a css-selector of your coice. You can set expand-symbols, as the behaviour of the collapse/expand mechanism. You can set the colors of backgrounds without modifying you css files. the other colors are leaned on your site design.
If you find this plugin helpful to you, please feel free to spend me a cup of coffee :)

== Installation ==
1. You can either use the automatic plugin installer or your FTP program to upload it to your wp-content/plugins directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Visit your Responsive Navigation Options (Settings --> Responsive Nav)
4. Set options as desired, click save to store the options in your WordPress database.
5. That's it!
