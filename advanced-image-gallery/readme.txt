Advanced Image Gallery is a versatile plugin for creating stunning media grids, carousels, gallery, and slideshows with an ease way.

== Description ==

Boost your Elementor website with the Advanced Image Gallery Plugin, featuring Grid, Carousel, and Slideshow layouts powered by Swiper.js. This versatile plugin is designed to showcase your images beautifully across any device, offering a seamless user experience and enhancing visual engagement.


**Features:**
- User-Friendly Interface for creating media grids, carousels, and slideshows
- Customizable Layouts & Animations for dynamic displays
- Fully Responsive design across all devices
- Theme Compatibility for seamless integration
- Custom Navigation & Pagination options (Arrows, Dots, Fraction, Progress)
- On/Off Controls for Navigation, Pagination, and Autoplay
- Custom URL & YouTube Links for media items
- Hover Text Overlays for interactive image effects
- Lightbox Integration for full-screen media viewing
- Advanced Animation Effects for smooth transitions
- And much more...

== Requirements ==

* Wordpress
* Elementor

== Installation ==

1. Upload the `advanced-image-gallery` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to Elementor and add the Advanced Image Gallery - Grid, Carousel & Slideshow widget to your page.
4. Customize the widget settings to create your desired media display.

== Frequently Asked Questions ==

= How do I add a media grid, carousel, or slideshow to my page? =
After activating the plugin, go to Elementor and drag the Advanced Image Gallery - Grid, Carousel & Slideshow widget onto your page. You can then customize the settings to create a media grid, carousel, or slideshow.

= Can I use this plugin without Elementor? =
No, Advanced Image Gallery is designed to work specifically with Elementor, leveraging its powerful page-building capabilities.

= Is the plugin responsive? =
Yes, all media displays created with Advanced Image Gallery are fully responsive and look great on all devices.

= Can I customize the appearance of the media displays? =
Yes, the Advanced Image Gallery - Grid, Carousel & Slideshow widget offers various customization options, including layout, animation, and display settings.
