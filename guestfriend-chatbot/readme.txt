== Description ==

<strong>Important Note: </strong>

Guestfriend instantly creates a unique chatbot for your restaurant. It’s easy to edit and set up, 
and will start responding to your customers on your website, on Facebook, and via SMS in minutes. 

It's the simplest way to add your Guestfriend chat bot to your WordPress site using widget or shortcode [ggf-chatbot].

== Guestfriend Chat Bot in 3 steps: ==

1: Install Guestfriend Chat Bot plugin.
2: Fill in the app key.
3: Just drag the widget or add to any post/page using shortcode [ggf-chatbot].

== Installation ==

1. Upload `guestfriend-chatbot` folder to the `/wp-content/plugins/` directory.ß
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Fill in the app key that appears in your admin menu.
3. Add the Chat Bot to any post/page using shortcode [ggf-chatbot] or drag the widget.
