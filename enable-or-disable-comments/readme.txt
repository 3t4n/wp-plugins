Enable or Disable Comments plugin can be used to easily disable comments for your blog posts, pages, attachments, etc. 


== Description ==

Enable or Disable Comments plugin is a simple and powerful tool that can be used by admin to globally disable comments on whole website. It includes all posts, pages, attachments, etc. It uses smart algorithm which remove all comment related features and options from Dashboard, Widgets and Admin menu. 

If you are planning to use comments somewhere on your website then you don't have to use this Enable or Disable Comments plugin. You can selectively turn off this functionality in required section of your Wordpress website. 


== Installation ==

* Upload the Enable or Disable Comments plugin to the `/wp-content/plugins/` directory
* Activate the Enable or Disable Comments plugin through the 'Plugins' menu in WordPress


== Frequently Asked Questions ==

= How to use Enable or Disable Comments plugin? = 
* Got to Wordpress Settings > Enable Disable Comments.
* You can enable or disable comments on this page. 

= How to successfully use plugin? =
* Before using Enable or Disable Comments plugin, most effective would be to delete existing comments to avoid any conflicts with your current theme. Depending on the theme code existing comments can stay published. 

= What to do if some comments interface elements stay published after plugin activation? =
* This is could be a reason of some conflict because of using a custom theme. Custom coded theme could overwrite some elements styles and layouts. 

= How to disable comments for some particular post? =
* To disable comments for a particular post, go to the edit page for the post for which you want to disable comments. 
* Scroll down to "Discussion" box. 
* You will find the comment options for that post. 
* If you don't see a "Discussion" box, click on "Screen Options" at the top of the screen, and make sure "Discussion" checkbox is checked.
