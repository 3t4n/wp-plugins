External links in new tab


== Description ==

After plugin activation all external links in your website will open in a new tab.
Those links will also get a rel=nofollow attribute.

= Plugin Setup =
- Install The plugin
- Activate.

== Installation ==

= Automatic installation =

Automatic installation is the easiest option as WordPress handles the file transfers itself and you don’t need to leave your web browser.
To do an automatic install of External links new tab - nofollow , log in to your WordPress dashboard, navigate to the Plugins menu and click Add New.

In the search field type “External links new tab - nofollow” and click Search Plugins.
Once you’ve found the plugin you can view details about it such as the point release, rating and description.
Most importantly of course, you can install it by simply clicking “Install Now”.

= Manual installation =

The manual installation method involves downloading External links new tab - nofollow plugin and uploading it to your webserver via your favourite FTP application.
The WordPress codex contains [instructions on how to do this here](https://codex.wordpress.org/Managing_Plugins#Manual_Plugin_Installation).

= Updating =

Automatic updates should work like a charm; as always though, ensure you backup your site just in case.
