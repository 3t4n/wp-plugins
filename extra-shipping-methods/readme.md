# Coffee Code - Extra Shipping Methods

**Requires at least:** 6.0
**Tested up to:** 6.6
**Stable tag:** 1.1

## Description

Plugin with extra shipping methods for Woocommerce.

### Compatibility

WooCommerce version 8.x

### Installation

- Install and active the plugin
- `Menu` WooCommerce -> Settings -> Shipping
- Add Access Token

### Required

- WordPress >= 6.0
- WooCommerce lastest version
- PHP >= 7.4
