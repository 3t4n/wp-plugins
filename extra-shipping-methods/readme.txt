== Description ==

Plugin with extra shipping methods for Woocommerce.

Support [Coffee Code](https://coffee-code.tech/#contact).

= Requirements =

- PHP version 7.4 or higher.
- WooCommerce version 7.0.x or higher.

== Installation ==

1. Upload this plugin to your WordPress, and activate it;
2. Go to the side menu "WooCommerce > Settings > Shipping";
3. Add and configure the custom shipping method.
4. Add Title and application rules.
