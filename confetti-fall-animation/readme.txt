Confetti fall animation fireworks celebration plugin for your blog or webpage. Add a delightful falling confetti animation to your website.

==============================================================================

=== How to Use ===

1. Go to the WordPress plugin directory.  
2. Search for the Confetti Fall Animation plugin, then install and activate it.  
3. Activate the confetti fall animation on the homepage by clicking the button or use the shortcode:  
   `[confetti-fall-animation delay="1" time="25"]`  
   on any post or page to start a falling confetti animation.  
4. Add the shortcode via the button in the page editing tools.  
5. Enjoy the animation!  

===============================================================================

=== Installation ===

1. Go to the WordPress Plugin Directory.  
2. Search for "Confetti Fall Animation."  
3. Install and activate the plugin.  
4. Use the shortcode `[confetti-fall-animation delay="1" time="25"]` to add confetti animation to any page or post.  
5. Watch the demo: [YouTube Demo](https://youtu.be/wpq-ItO53vo).
