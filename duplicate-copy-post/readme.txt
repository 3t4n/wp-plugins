Easily duplicate posts with all custom fields and settings

== Description ==

Just One Click Duplicate.
Duplicate Copy Post allows you to duplicate posts, pages, or custom post types with just a few clicks. The plugin includes advanced options for duplication, as well as customizable settings profiles for different scenarios.

### Features:
* Duplicate posts inclduing all Custome fields, Yoast seo plugins settings everything.
* Just One Click on Button "Duplicate" on post page and copy of your post is ready.
* Seamless integration with the WordPress interface.
* Lightweight and easy to use.

This plugin is perfect for website administrators, content managers, and developers who frequently need to duplicate content while preserving custom settings.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/duplicate-copy-post` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. And ready to use.

== Frequently Asked Questions ==

= How do I duplicate a post? =
You can duplicate a post from the post list screen by clicking on the "Duplicate" link under each post.

= Does this plugin support custom post types? =
Yes, Duplicate Copy Post allows you to duplicate custom post types along with their associated metadata and taxonomies.
