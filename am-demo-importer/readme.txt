A simple plugin that allows you to import Elementor templates and dummy content with one click.

== Description ==  

Elementor Template Importer is a lightweight and easy-to-use plugin that allows you to import Elementor templates and dummy content with just one click. Whether you're setting up a new website or testing a design, this plugin simplifies the process by quickly bringing in ready-made content.  

== Features ==  

- One-click demo content import  
- Seamless integration with Elementor  
- Easy installation and activation  
- Lightweight and optimized for performance  

== Installation ==  

= Minimum Requirements =  

- PHP version 7.4 or greater  
- MySQL version 5.0 or greater  

= Recommended Hosting Setup =  

- PHP version 7.4 or greater  
- MySQL version 5.6 or greater  
- WordPress Memory limit of 64 MB or greater (128 MB or higher is preferred)  

= Installation Steps =  

1. Install via the WordPress built-in Plugin installer, or manually extract the zip file and upload it to the `wp-content/plugins/` directory of your WordPress installation.  
2. Activate the plugin through the 'Plugins' menu in WordPress.
