== Description ==

**Soft Accordion** is the ultimate responsive **Accordion FAQ Builder** plugin for WordPress, designed to help you display collapsible content effortlessly. Whether you're creating FAQs, product details, or interactive lists, this plugin offers highly customizable features to fit your site perfectly.

== Frequently Asked Questions ==
= How do I add an accordion to my WordPress site? =
Simply create an accordion using the plugin’s and use the provided shortcode to insert it into your posts or pages.

= Is Soft Accordion Responsive? =
Yes, **Soft Accordion** is fully responsive, ensuring it looks great on all devices, from desktops to mobiles.

= Is Soft Accordion Compatible with Popular Themes? =
Yes, **Soft Accordion** is fully compatible with popular themes (Divi, Astra, Kadence, Generatepress, and others), ensuring smooth integration and seamless functionality.

= Can I display multiple accordions on one page? =
Yes, you can display multiple accordions on one page!

= Does this plugin offer FAQ Schema? =
Yes, this plugin offers FAQ Schema support to help your FAQs appear in rich snippets on search engines.

= Can I re-order my FAQ accordions? =
Yes, you can easily re-order your FAQ accordions using a simple drag-and-drop feature.

=  Can I customize accordion colors & styles? =
Yes, you can customize the accordion colors and styles to match your site’s design, giving you full control over its look and feel. Also, you can choose our pre-designed templates to fit your design.

= Is there a Gutenberg block to display FAQs? =
A Gutenberg block to display FAQs is coming soon. This new feature will allow you to easily create and customize FAQ sections directly within the Gutenberg editor. You’ll be able to add, organize, and style your FAQs without any hassle, making it simpler to provide helpful information to your website visitors.

= Are the accordions searchable? =
Yes, the accordions are searchable. They include a feature that allows users to search for any content within the accordion, making it easier to find specific information quickly.

= Is Soft Accordion Translation Ready? =
Yes, Soft Accordion is translation-ready. This means it is designed to support multiple languages, allowing users to easily translate its content and interface to different languages for a global audience.

= Can I keep the accordion items active on load? =
Yes, you can keep the accordion items active on load. This allows specific items to be opened by default when the page is loaded, providing a better user experience.

= Can I animate the accordions? =
Yes, you can animate the accordions. The accordion items can be animated for smooth transitions, adding a dynamic and engaging effect when they open or close.

= Does Soft Accordion support Shortcode? =
Yes, Soft Accordion supports shortcodes. This feature allows you to easily insert and display accordions anywhere on your site using simple shortcodes.

= Is Soft Accordion compatible with the multisite network? =
Yes, Soft Accordion is compatible with multisite networks. It works smoothly across multiple sites within a network, allowing you to use the accordion functionality on all sites without issues.

= Will Soft Accordion slow down my site? =
No, Soft Accordion will not slow down your site. The code is optimized for performance, ensuring that it runs smoothly without affecting your site’s speed.
