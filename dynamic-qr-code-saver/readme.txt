Generates a dynamic QR-Code, which can be saved and edited later, even if the QR Code was printed. Very easy to install and use. Share smartly!

== Description ==

The DQRS (DynamicQRSaver) generates a dynamic QR-Code. This QR-Code / the URL gets saved in the Wordpress-Database and can be changed later on.
Simply edit the QR-Code URL in the Backend-Tab. 


== Installation ==

Automatic Installation<br>
1. Upload the zip-file with the wordpress plugininstaller.<br>
2. Activate the plugin through the 'Plugins' menu in WordPress<br>
3. Have fun<br>
Optional: Share it with your firends<br>

Manual Installation<br>
1. Upload all files, of the archiv, to the wordpress Plugin directory<br>
2. Activate the plugin through the 'Plugins' menu in WordPress<br>
3. Have fun<br>
Optional: Share it with your firends<br>
