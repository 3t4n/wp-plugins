== Installation ==

To get started:

1. From WordPress Admin page, go to "Plugins" from left sidebar, then click "Add New Plugin"
2. Search for "Alt Text Go", click "Install", then "Activate"
3. Go to [AltTextGo website](https://app.alttextgo.com/signup) to sign up and create an API key with free credits
4. Go back to WordPress -> "Alt Text Go", paste the API key into plugin Settings Page.
5. You're ready! Go to any image and generate alt text in one click.
