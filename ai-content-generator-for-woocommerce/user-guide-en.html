AI Content Generator for WooCommerce - User Guide

Version 1.0.0 | Compatible with WordPress 6.7 and WooCommerce 9.5

Overview

AI Content Generator for WooCommerce is a powerful tool that helps you automatically generate high-quality product content using ChatGPT API. This includes product images, descriptions, and gallery images, all generated based on your product details.

System Requirements

  • WordPress 5.0 or higher
  • WooCommerce 4.0 or higher
  • PHP 7.2 or higher
  • Valid ChatGPT API key

Getting Started

Obtaining a ChatGPT API Key

  1. Visit the OpenAI Platform
  2. Create an account or sign in
  3. Go to API Keys section
  4. Click "Create new secret key"
  5. Copy your API key immediately (you won't be able to see it again)
Important: OpenAI API is a paid service. You'll need to add billing information to your account. Costs are based on usage - see OpenAI's pricing page for current rates.

Installation

  1. Upload the plugin files to /wp-content/plugins/ai-content-generator-for-woocommerce
  2. Activate the plugin through the 'Plugins' menu in WordPress
  3. Navigate to WooCommerce > Settings > AI Content Generator
  4. Enter your ChatGPT API key

Features

1. Product Images Generation

  • Featured Images:
    • Click "Generate Featured Image" in the product editor
    • Select from multiple AI-generated options
    • Click "Use as Featured" to set your chosen image
  • Gallery Images:
    • Use "Generate Gallery Images" button
    • Select multiple images using checkboxes
    • Batch add images to your product gallery

2. Product Description Generation

  • Available Tones:
    • Formal & Professional
    • Casual & Friendly
    • Persuasive & Sales-focused
    • Technical & Detailed
    • Luxury & Premium
    • Creative & Engaging
  • Generation Options:
    • Full product descriptions
    • Short descriptions
    • Preview before applying
    • Regenerate if needed

Using the Plugin

Generating Content

  1. Edit or create a product in WooCommerce
  2. Find the AI generation tools in the product editor:
    • "Generate Featured Image" box
    • "Generate Gallery Images" box
    • Description generation buttons near content editors
  3. Select your preferred tone for descriptions
  4. Click generate and preview the results
  5. Apply the content you like
Pro Tip: For best results, ensure your product has basic information like title, categories, and tags before generating content.

Troubleshooting

Debug Mode

Enable debug mode in settings to log API responses. Access logs at WooCommerce > Status > Logs (look for 'webtoffee-ai' source).

Common Issues:

  • API Key Issues: Ensure your ChatGPT API key is valid and has sufficient credits
  • Image Generation Fails: Check your API key permissions include image generation
  • Timeout Errors: Try regenerating if the API is slow to respond
