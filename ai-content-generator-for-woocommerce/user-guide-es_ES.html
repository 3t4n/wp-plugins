Generador de Contenido AI para WooCommerce - Guía de Usuario

Versión 1.0.0 | Compatible con WordPress 6.7 y WooCommerce 9.5

Descripción General

El Generador de Contenido AI para WooCommerce es una herramienta potente que te ayuda a generar automáticamente contenido de alta calidad para productos utilizando la API de ChatGPT. Esto incluye imágenes de productos, descripciones e imágenes de galería, todo generado basado en los detalles de tu producto.

Requisitos del Sistema

  • WordPress 5.0 o superior
  • WooCommerce 4.0 o superior
  • PHP 7.2 o superior
  • Clave API de ChatGPT válida

Primeros Pasos

Obtener una Clave API de ChatGPT

  1. Visita la Plataforma OpenAI
  2. Crea una cuenta o inicia sesión
  3. Ve a la sección de Claves API
  4. Haz clic en "Create new secret key"
  5. Copia tu clave API inmediatamente (no podrás verla de nuevo)
Importante: La API de OpenAI es un servicio de pago. Necesitarás agregar información de facturación a tu cuenta. Los costos se basan en el uso - consulta la página de precios de OpenAI para las tarifas actuales.

Instalación

  1. Sube los archivos del plugin a /wp-content/plugins/ai-content-generator-for-woocommerce
  2. Activa el plugin a través del menú 'Plugins' en WordPress
  3. Ve a WooCommerce > Ajustes > Generador de Contenido AI
  4. Ingresa tu clave API de ChatGPT

Características

1. Generación de Imágenes de Producto

  • Imágenes Destacadas:
    • Haz clic en "Generar Imagen Destacada" en el editor de productos
    • Selecciona entre múltiples opciones generadas por IA
    • Haz clic en "Usar como Destacada" para establecer tu imagen elegida
  • Imágenes de Galería:
    • Usa el botón "Generar Imágenes de Galería"
    • Selecciona múltiples imágenes usando casillas de verificación
    • Agrega imágenes por lotes a tu galería de productos

2. Generación de Descripciones de Producto

  • Tonos Disponibles:
    • Formal y Profesional
    • Casual y Amigable
    • Persuasivo y Orientado a Ventas
    • Técnico y Detallado
    • Lujo y Premium
    • Creativo y Atractivo
  • Opciones de Generación:
    • Descripciones completas de productos
    • Descripciones cortas
    • Vista previa antes de aplicar
    • Regenerar si es necesario

Uso del Plugin

Generando Contenido

  1. Edita o crea un producto en WooCommerce
  2. Encuentra las herramientas de generación AI en el editor de productos:
    • Caja "Generar Imagen Destacada"
    • Caja "Generar Imágenes de Galería"
    • Botones de generación de descripción cerca de los editores de contenido
  3. Selecciona tu tono preferido para las descripciones
  4. Haz clic en generar y revisa los resultados
  5. Aplica el contenido que te guste
Consejo Pro: Para mejores resultados, asegúrate de que tu producto tenga información básica como título, categorías y etiquetas antes de generar contenido.

Solución de Problemas

Modo de Depuración

Habilita el modo de depuración en la configuración para registrar las respuestas de la API. Accede a los registros en WooCommerce > Estado > Registros (busca la fuente 'webtoffee-ai').

Problemas Comunes:

  • Problemas con la Clave API: Asegúrate de que tu clave API de ChatGPT sea válida y tenga créditos suficientes
  • Falla la Generación de Imágenes: Verifica que los permisos de tu clave API incluyan la generación de imágenes
  • Errores de Tiempo de Espera: Intenta regenerar si la API responde lentamente
