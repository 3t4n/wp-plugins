== Installation ==

* Install and activate the DiscoBars Plugin through the 'Plugins' menu in WordPress
* After installation, click the Settings → DiscoBars widget section in the left toolbar
* Create a new free DiscoBars account, or use your existing one. Log in into https://discobars.io in another browser tab and copy the widget code from Settings → Tracking code section.
* Go back to Wordpress console, paste the code and press Save changes
* Done!
