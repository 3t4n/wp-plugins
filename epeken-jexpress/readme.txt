JExpress plugin is a wordpress plugin for woocommerce users in Indonesia to integrate JExpress courier shipping cost information with woocommerce based online shop.

== Description == 

Halo Kak!, Plugin ini adalah plugin yang dapat mengintegrasikan data ongkos kirim kurir JExpress dengan toko online Kakak yang berbasis wordpress dan woocommerce di Indonesia.

== Installation == 

Cara menginstal plugin ini mudah, Kak. Kakak dapat dilakukan dari wp-admin Add Plugin dengan mencari plugin ini di repositori wordpress. Atau, dapat mengunduh plugin ini dari repository wordpress dalam format zip.
Lalu, dapat menginstal dengan cara upload file zip tersebut di wp-admin. Prasyarat untuk menggunakan plugin ini adalah, Kakak perlu menginstal plugin Epeken All Kurir dengan license yang valid. Dapatkan license plugin Epeken [di sini](https://www.epeken.com/shop/epeken-all-kurir-license). 

= Minimum Requirement =

* Wordpress 4.0 or greater
* Woocommerce version 3.0 or greater
* PHP version 5.2.4 or greater
* MySQL version 5.0 or greater
* Epeken All Kurir version 1.1.8.6.26 or greater

= Updating =

Automatic updates should work like a charm; as always though, ensure you backup your site just in case.
