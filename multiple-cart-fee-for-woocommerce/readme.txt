== Description ==

**multiple Cart Fee for WooCommerce** is a powerful and user-friendly plugin that allows you to add multiple conditional fees to your WooCommerce cart. Whether you need to add handling charges, special service fees, or product-specific surcharges, this plugin makes it simple and flexible.

### 🌟 Key Features

* **Multiple Fee Support**: Add unlimited fees with custom names and amounts
* **Smart Conditions**: Apply fees based on specific products, categories, or tags
* **Cart Total Rules**: Set minimum and maximum cart amounts for fee application
* **Easy Management**: Intuitive interface for adding and managing fees
* **HPOS Compatible**: Fully compatible with WooCommerce High-Performance Order Storage
* **Variation Support**: Works with both simple products and variations

### 💼 Perfect For

* Online stores needing handling fees
* Shops with special delivery charges
* Businesses with product-specific surcharges
* Stores requiring category-based fees
* Any WooCommerce store needing flexible fee management

### 🔥 Professional Features

* **Dynamic Fee Application**: Fees automatically adjust based on cart contents
* **Flexible Conditions**: Mix and match products, categories, and tags
* **Bulk Management**: Easily manage multiple fees from one interface
* **Cart Total Control**: Apply fees only within specific cart value ranges
* **Clean Interface**: User-friendly admin panel for easy configuration

### 🛠️ Easy Setup

1. Install and activate the plugin
2. Go to WooCommerce → Settings → multiple Cart Fees
3. Add your fees and set conditions
4. Save and start applying fees automatically!

### 💡 Use Cases

* Add handling fees for specific product categories
* Apply special charges for premium products
* Set service fees based on cart value
* Add packaging fees for certain product types
* Implement conditional surcharges

== Installation ==

1. Upload `multiple-cart-fee-for-woocommerce` to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to WooCommerce → Settings → multiple Cart Fees to configure
4. Add your fees and set your conditions
5. Save changes and test with different cart scenarios

== Frequently Asked Questions ==

= Can I add multiple different fees? =

Yes! You can add unlimited fees with different names and amounts. Each fee can have its own conditions.

= Does it work with product variations? =

Absolutely! The plugin fully supports both simple products and product variations.

= Can I set minimum/maximum cart amounts? =

Yes, you can set both minimum and maximum cart amounts to control when fees should be applied.

= Is it compatible with the latest WooCommerce? =

Yes, we maintain regular updates to ensure compatibility with the latest versions of WordPress and WooCommerce.

= Can I apply fees to specific categories only? =

Yes, you can select specific categories, products, or tags to apply your fees to.
