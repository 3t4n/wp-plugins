== Description ==

实现视频上传到阿里云，实现文章能播放视频，大量节约服务器带宽流量，视频点播是集视频采集、编辑、上传、媒体资源管理、自动化转码处理（窄带高清™）、视频审核分析、分发加速于一体的一站式音视频点播解决方案


## 功能概述

* 支持后台媒体库上传视频到阿里云视频点播，实现流量走云端，不消耗本身服务器的流量，在云端播放视频
* 支持选择所属地域
* 支持文章插入视频及播放视频+
* 支持加密播放视频，防止视频被盗用
* 支持自定义视频宽度
* 支持自定义视频高度
* 支持阿里云播放器播放视频
