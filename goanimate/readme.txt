Adding animation to your html elements has never been more simple.

== Description ==

Go Animate offers various modern css3 animations for html elements and you can choose from a list of 75 different kinds.
Offers also the possibility to modify the animation. By adding delay,repetition,duration.

== Installation ==

Add this awesome plugin to your website

From online repository
1- Go to Plugins->Add New.
2- Search for 'go animate' plugin.
3- From the results click "Install".
4- Click Plugins again on wordpress and active the plugin.

Installing localy
Copy folder 'goaniamte' inside wp-content/plugins,
Go to Plugins at wordpress backend and click "Activate".
