== Description ==
**Anywhere Elementor Template by Shortcode** plugin allows users to display Elementor sections/canvas/templates anywhere on their WordPress site.

**How to use?**
By shortcode: `[AETS_Template id='123']` - use template's id, instead 123.
Tips: Go to Dashboard -> Templates (find shortcode from Shortcode column).

**Key Features:**

* **Use Templates Anywhere** – Effortlessly insert your Elementor-created templates into any section of your WordPress site.
* **Shortcode Integration** – Simply copy and paste the generated shortcode to display your template in pages, posts, widgets, or other builder elements.
* **Seamless Compatibility** – Works with any WordPress theme or page builder, ensuring maximum flexibility.

Take your Elementor designs to the next level with this powerful and easy-to-use plugin!

== Installation ==

1. Upload 'anywhere-elementor-template' to the '/wp-content/plugins/' directory
2. Activate the plugin through the 'Plugins' menu in WordPress

= Menu Location =

🔅 Dashboard -> Elementor -> Saved Templates
